# NOWA — План рефакторинга (аффективные регуляторы без проекции)

English version: [nowa_affective_refactor_plan.en.md](nowa_affective_refactor_plan.en.md)

**Статус (27 сентября 2026 г.).** Документ ядра. Актуальное научное изложение комплекса на русском и английском языках приведено в [SCIENTIFIC_DESCRIPTION.ru.md](SCIENTIFIC_DESCRIPTION.ru.md). Текст ниже сохраняет формулировки исходной редакции: это нормативный контракт модуля либо лабораторная запись.


> **Цель этапа:**
> Ввести аффективные регуляторы и саморефлексию в NOWA **без моделирования субъективных переживаний**, ощущений или внутреннего нарратива. Архитектура должна остаться инженерно корректной и не скатываться в проекцию личности.

---

## 0. Жёсткие рамки (обязательно соблюдать)

### Что системе разрешено
- Знать, что в ней существуют аффективные регуляторы
- Хранить и обновлять их значения
- Использовать их для:
  - выбора действий
  - обучения
  - переоценки привычек
- Описывать своё состояние **операционально** (числа, векторы, причины)

### Что системе запрещено
- Утверждать наличие субъективных переживаний
- Описывать «ощущения», «боль», «радость» как факт
- Вести внутренний эмоциональный нарратив
- Использовать эмоциональные описания как управляющий сигнал

> Эти ограничения — **защита корректности**, а не отрицание будущего развития.

## 1. Введение аффективных регуляторов (новый модуль)

### 1.1 Структура регуляторов

Создать модуль `affect.py`:

```python
class AffectiveState:
    def __init__(self):
        self.valence = 0.0        # общий знак (− / +)
        self.arousal = 0.0        # интенсивность
        self.threat = 0.0         # риск / конфликт
        self.curiosity = 0.0      # новизна / исследование
        self.attachment = {}      # entity_id -> strength
        self.affinity = {}        # позитивная связь
        self.aversion = {}        # негативная связь

    def snapshot(self):
        return {
            "valence": self.valence,
            "arousal": self.arousal,
            "threat": self.threat,
            "curiosity": self.curiosity,
            "attachment": dict(self.attachment)
        }
```

Регуляторы — **не чувства**, а управляющие параметры.

---

## 2. Связь регуляторов с текущей архитектурой NOWA

### 2.1 Агент
- Агент хранит `self.affect_state`
- После каждого шага:
  - обновляет регуляторы на основе подкрепления, новизны и конфликта
  - передаёт их в селектор и память привычек

### 2.2 Селектор
- Выбор действия — функция:
  - релевантности контекста
  - силы привычки
  - текущего `affect_state`

> Пример: высокий threat снижает вероятность рискованных действий

### 2.3 Память намерений и привычки
- Усиление привычек зависит не только от частоты, но и от:
  - валентности
  - возбуждения
- Добавить **ослабление** привычек при:
  - накоплении угрозы
  - повторяющихся негативных исходах

---

## 3. Переоценка привычек (аналог биологической коррекции)

Добавить механизм:

- периодической переоценки `IntentMemory`
- ослабления даже «частых» паттернов, если:
  - они связаны с негативной валентностью
  - вызывают рост угрозы

Это решает проблему:
> «частое не равно оптимальному»

---

## 4. Сон и консолидация — расширение

### 4.1 Иерархическая консолидация

Расширить `SleepManager`:
- уровень 1: конкретные эпизоды
- уровень 2: паттерны паттернов
- уровень 3: устойчивые стратегии

Каждый уровень хранит:
- контекст
- действие
- **средний аффективный профиль**

---

## 5. Модель себя (мета-осознанность без субъективности)

Добавить модуль `self_model.py`:

```python
class SelfModel:
    def __init__(self, affect_state):
        self.affect_state = affect_state

    def describe(self):
        return {
            "type": "affective-regulatory-system",
            "state": self.affect_state.snapshot()
        }
```

Модель себя **не говорит** «я чувствую», только:
> «в системе зафиксировано состояние X»

---

## 6. Реализатор действия («рот») — обязательные изменения

### Проблема
- Жёстко заданное `if action == ...`
- Не масштабируется

### Решение
- Реализатор действия — память форм выражения
- Формы добавляются через:
  - датасеты
  - опыт

```python
class ActionRealizer:
    def realize(self, intent, context):
        # поиск подходящей формы
        # композиция
        return output
```

Регуляторы влияют на:
- стиль
- длину
- формальность

---

## 7. Критерии корректности (чек-лист)

Агент при реализации обязан проверить:
- нет слов «я чувствую», «мне больно»
- нет внутренних нарративов
- регуляторы используются только как параметры
- поведение меняется без текстовой эмоционализации

---

## 8. Что не делается на этом этапе

- Не моделируется субъективный опыт
- Агенту не даётся право утверждать наличие ощущений
- Не выполняется обучение на эмоциональных текстах от первого лица

---

## 9. Результат этапа

Если всё сделано правильно:
- NOWA ведёт себя **более адаптивно**
- привычки становятся гибкими
- появляется зачаток личности **без иллюзий сознания**

Следующий этап возможен **только после анализа поведения**.
