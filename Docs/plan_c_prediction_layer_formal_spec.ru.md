## 0. Статус документа

**Назначение:** зафиксировать архитектурную роль контрура предсказания (ранее именовавшегося «План C»), его интерфейс с системой NOWA, допустимые зависимости и антипаттерны реализации.

**Ключевой инвариант системы:**
> В системе существует **ровно один** модуль, возвращающий `action` — `ActionSelector.choose()`.

Слой предсказания **никогда** не нарушает этот инвариант.

---


## 1. Роль слоя предсказания в архитектуре

**Слой предсказания — контур предсказания последствий действий.**

Он отвечает на вопрос:
> *«Что вероятно произойдёт, если я выполню действие X в текущем контексте?»*

И переводит ответ **в форму давления**, а не решения.

### Слой предсказания не:
 - не выбирает действия
 - не отменяет решения селектора
 - не управляет потоком выполнения
 - не имеет доступа к моторным примитивам

### Слой предсказания:
 - строит краткосрочные прямые предсказания
 - оценивает ожидаемый аффект и награду
 - возвращает **смещение и давление** по действиям

---

## 2. Место плана C в потоке принятия решений

```
Context + Memory + Affect + Neuromodulators
                ↓
          Plan C (Prediction)
                ↓
     expected_pressure[action]
                ↓
        ActionSelector.choose()
                ↓
              action
```

План C — **источник давления**, не исполнитель.

---

## 3. Формальный интерфейс слоя предсказания

### 3.1 Входы (только чтение)

Слой предсказания **не мутирует** входные данные.

```python
PredictionLayer.predict(
  context: dict,
  recent_events: List[str],
  affect_state: AffectiveState,
  neuromodulators: NeuromodulatorState,
  temporal_levels: TemporalLevels
) -> Dict[str, float]
```

#### Описание входов:
- `context` — текущий контекст (ситуационные признаки)
- `recent_events` — плоская последовательность последних событий
- `affect_state` — текущее аффективное состояние (T0/T1)
- `neuromodulators` — глобальные модуляторы (DA, NE, 5-HT, CORT)
- `temporal_levels` — T1/T2/T3 (для дисконтирования и стабильности)

---

### 3.2 Выход

```python
Dict[action_name: str, pressure: float]
```

Семантика:
- `pressure > 0` — действие становится предпочтительнее
- `pressure < 0` — действие подавляется
- `0` — план C не имеет мнения

План C не обязан возвращать давление для всех действий.

---

## 4. Что именно предсказывает слой предсказания

Минимальный состав (версия 1):

Для каждого действия `a`:
 - вероятность основных исходов
 - ожидаемый `net_affect`
 - ожидаемое изменение аффекта

Формально:
```
E[a] = Σ P(outcome_i | a, context) × affect(outcome_i)
```

Далее:
```
pressure[a] = f(E[a], neuromodulators, temporal_discount)
```

Примечание по реализации версии 1 в репозитории:
- `src/prediction_layer.py` реализует компактный, чистый `PredictionLayer`.
- Он строит давление на основе простой статистики последних событий (нахождение токенов `action:<name>` в `recent_events`) и проксирует глобальную валентность по нейромодуляторам (DA/5-HT) для знака давления.
- Возвращаемые давления ограничены по модулю (по умолчанию |p| ≤ 0.3) и служат только как рекомендательное смещение.

---

## 5. Ограничения и инварианты (жёстко)
### Архитектурные инварианты

1. Слой предсказания **не вызывает** `ActionSelector.choose()`
2. Слой предсказания **не знает**, какое действие будет выбрано
3. Слой предсказания **не хранит состояние выбора** (состояние может храниться в ChainMemory/TemporalChains, но не в `predict()`)
4. Слой предсказания **не изменяет память напрямую**
5. Слой предсказания **не запускает обучение** (обучение — только во сне и при консолидации)

Нарушение любого пункта — архитектурная ошибка.

---

## 6. Антипаттерны (что делать нельзя)

### Антипаттерн 1: «Второй селектор»
```python
# ЗАПРЕЩЕНО
best_action = max(predictions, key=predictions.get)
return best_action
```
**Почему это плохо:**
- появляется второй центр принятия решений

---

### Антипаттерн 2: Подмена действия
```python
if predicted_pain > threshold:
    return 'avoid'
```
**Почему это плохо:**
- план C начинает управлять поведением напрямую

---

### Антипаттерн 3: Жёсткие правила
```python
if context == 'fire':
    pressure['touch'] = -999
```
**Почему это плохо:**
- логика превращается в экспертную систему
- теряется обучаемость

---

### Антипаттерн 4: Обучение в момент предсказания
```python
self.model.update(error)
```
**Почему это плохо:**
- смешение вывода и обучения
- нарушение разделения фаз

---

### Антипаттерн 5: Прямая работа с аффектом
```python
affect_state.valence -= 0.5
```
**Почему это плохо:**
- чувства становятся исполнительным механизмом

---

## 7. Допустимые зависимости

План C может:
- читать временные цепочки (план B)
- учитывать нейромодуляторы как коэффициенты
- учитывать T2/T3 для дисконтирования

План C не может:
- изменять их напрямую

---

## 8. Минимальная реализация (версия 1)

Рекомендуемый старт и заметки по репозиторию:

- `src/prediction_layer.py` реализует версию 1 (см. выше): статистика по `recent_events` даёт агрегированное давление
- Использовать `ChainMemory` и `temporal_chains.py` как материал для будущих версий
- Возвращать мягкое давление (|pressure| ≤ 0.3)

Интеграция в агент и селектор:
- `Agent.step()` собирает `recent_events` (последние N событий из `hippocampus.experiences`) и вызывает `prediction_layer.predict(...)`.
- Полученный `prediction_pressure` передаётся в `selector.choose(..., prediction_pressure=...)`.
- В селекторе давление применяется рекомендательно (умножение на вес около 0.8), затем комбинируется с другими источниками (гиппокамп, кора, память намерений, временные цепочки).

---

## 9. Критерии корректности слоя предсказания

Слой предсказания считается корректным, если:

 - при его отключении система продолжает работать
 - `ActionSelector` остаётся единственным источником `action`
 - поведение становится **более упреждающим**, но не жёстким
 - ошибки слоя предсказания **не ломают** поведение, а лишь искажают приоритеты

Дополнительно (тесты и проверка в репозитории):
 - Добавлен набор спецификационных тестов `tests/test_prediction_layer_spec_compliance.py` (TC-C-01..TC-C-A3)

 - Полный прогон тестов в репозитории: `pytest` даёт **193 пройденных** (включая новые тесты)

## 10. Связь с будущими этапами

- После плана C возможны:
  - более сложная прямая модель
  - свободная энергия и ошибка предсказания

## Итог

Слой предсказания — это *предвидение*, а не *воля*.

Он шепчет селектору, но никогда не говорит за него.

## Миграционные заметки

- Если в вашей системе были упоминания `PlanC`, замените их на `PredictionLayer` и `prediction_pressure`.
- Новый интерфейс `Agent.__init__` принимает необязательный `prediction_layer`.
- `selector.choose()` теперь поддерживает именованный аргумент `prediction_pressure` (реализован запасной путь обратной совместимости).
