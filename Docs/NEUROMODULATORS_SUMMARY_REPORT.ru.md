## Обзор

Реализована полная система нейромодуляторов, которая модулирует процессы обучения и консолидации памяти через четыре глобальных регуляторных сигнала: Dopamine (DA), Norepinephrine (NE), Serotonin (5-HT) и Cortisol (CORT).

## Архитектурные изменения

### 1. Новый модуль: `src/neuromodulators.py`

**Размер:** ~90 строк кода

**Класс `NeuromodulatorState`:**
- 4 атрибута (dopamine, norepinephrine, serotonin, cortisol)
- Методы: `update_from_signals()`, `decay_over_time()`, `to_dict()`, `from_dict()`, `snapshot()`
- Все значения нормализованы к [0.0, 1.0]

**Основная логика:**
```
reward > 0     → DA ↑, 5-HT ↑
novelty > 0    → NE ↑
conflict > 0   → CORT ↑, NE ↑
reward < 0     → CORT ↑, DA ↓
все=0          → 5-HT ↑ (очень медленно)
```

### 2. Интеграция в `src/agent.py`

**Изменения:**
- Инициализация: `self.neuromodulators = NeuromodulatorState()`
- В `step()`: вызов `neuromodulators.update_from_signals(reward, novelty, conflict)`
- В `get_state()`: добавлен вывод `neuromodulators.snapshot()`
- Подключение к `sleep_manager` для применения эффектов

**Коммит в `__init__`:**
```python
setattr(self.sleep_manager, "neuromodulators", self.neuromodulators)
```

### 3. Применение эффектов в `src/sleep.py`

**Новый метод: `_apply_neuromodulators_during_sleep()`**

| Нейромодулятор | Условие | Эффект |
|---|---|---|
| DA | DA > 0.05 | `pattern.strength *= (1.0 + da * 0.05)` |
| NE | NE > 0.4 | `_form_chains_from_recent(max_len=9)` |
| 5-HT | 5-HT > 0.1 | `exp.stability += serotonin * 0.01` |
| CORT | CORT > 0.4 | Повышение порога забывания |

**Вызов в `sleep_cycle()`:**
```python
if hasattr(self, 'neuromodulators'):
    self._apply_neuromodulators_during_sleep()
```

### 4. Сохранение/Загрузка в `src/storage.py`

**Изменения:**
- `save_agent()`: добавлен параметр `neuromodulators=None`
- Сохранение: `agent_state['neuromodulators'] = neuromodulators.to_dict()`
- Загрузка: восстановление из `NeuromodulatorState.from_dict()`

**Совместимость:**
- Обратная совместимость: если `neuromodulators=None`, всё работает без них
- Если загружаем старые сохранения, нейромодуляторы инициализируются с базовыми значениями

### 5. Визуализация в `src/gui.py`

**Добавлены элементы:**
- Новый блок "Нейромодуляторы:" в аффективной панели
- Четыре метки: `DA: 0.00`, `NE: 0.00`, `5-HT: 0.00`, `CORT: 0.00`
- Обновление в `update_affect_display()`:
```python
self.da_label.config(text=f"DA: {nm.dopamine:.2f}")
# ... аналогично для остальных
```

**Расположение:** Над блоком статистики (после Готовности)

**Дополнительные улучшения:**
- Боковая панель сделана прокручиваемой (Canvas + Scrollbar)

- Соотношение панелей: 80% (левая) : 20% (правая)

## Принципиальные решения

### 1. Отделение от Affect

**Почему нейромодуляторы отдельно от Affective State?**

| Аспект | Affect | Нейромодуляторы |
|---|---|---|
| Назначение | Текущее поведение | Модуляция обучения |
| Скорость | Быстро | Медленно |
| Видимость | Интерфейс | Диагностика |
| Масштаб времени | Текущий момент | Долгосрочный тренд |

### 2. Норма [0.0, 1.0]

Все нейромодуляторы нормированы для:
- Единообразного влияния
- Сравнимости между собой
- Расширяемости системы

### 3. Базовый уровень = 0.1

Обеспечивает:
- Фоновый тонус системы
- Быстрый спад к норме после стресса
- Различие между низким и высоким состояниями

### 4. Эффекты только во время сна

Нейромодуляторы **не влияют прямо на выбор действия** — это сохраняет принцип "физики без психологии". Они влияют на:
- Консолидацию опытов в паттерны
- Формирование цепочек
- Забывание нестабильных трасс

Изменённые паттерны и цепочки потом косвенно влияют на будущие выборы.
