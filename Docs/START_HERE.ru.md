## Помощь

### Потерялись в документации
Смотрите [INDEX.md](INDEX.ru.md) — полный указатель.

### Интерфейс не запускается
1. Проверьте Python: `python --version` (должно быть 3.13+)
2. Проверьте tkinter: `python -c "import tkinter"`
3. Запустите из папки проекта: `cd e:\git\NOWA-Cognitive`

### Тесты не проходят
1. Удалите кэш: `del .pytest_cache -r`
2. Переустановите пакеты: `pip install pytest`
3. Запустите снова: `pytest tests/test_affective_regulators.py -v`

### Непонятно, как всё работает
Читайте [COMPLETE_PROJECT_REPORT.ru.md](COMPLETE_PROJECT_REPORT.ru.md) (части 1 и 2).

### Хотите модифицировать код
Смотрите [FILES_CHANGES_COMPLETE_LIST.md](FILES_CHANGES_COMPLETE_LIST.ru.md) и `src/*.py`.
