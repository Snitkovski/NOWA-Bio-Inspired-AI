## Обзор

Нейромодуляторная система реализует **четыре глобальные регуляторные сигналы**, которые влияют на консолидацию памяти, формирование цепочек и поведение системы **без субъективных переживаний**.

### Основной принцип

> **Нейромодуляторы — это физика системы, не психология.**

Они не принимают решений, не хранят смысл, а только модулируют вероятности, скорости и пороги процессов.

## Компоненты

### 1. NeuromodulatorState (`src/neuromodulators.py`)

Простой контейнер состояния нейромодуляторов:

```python
class NeuromodulatorState:
    dopamine: float          # 0.0–1.0
    norepinephrine: float    # 0.0–1.0
    serotonin: float         # 0.0–1.0
    cortisol: float          # 0.0–1.0
    timestamp: float
```

#### Методы

| Метод | Описание |
|-------|---------|
| `update_from_signals(reward, novelty, conflict)` | Обновление от окружающих сигналов |
| `decay_over_time(elapsed)` | Экспоненциальный спад к базовому уровню |
| `to_dict() / from_dict()` | Сериализация |
| `snapshot()` | Снимок текущего состояния |

### 2. Четыре нейромедиатора

#### DA (Dopamine) — Подкрепление / Ценность

**Источник:**
- Положительная награда (reward > 0)
- Успешная стабилизация паттернов
- Укрепление положительных цепочек

**Влияет на:**
- ↑ Усиление силы кортикальных паттернов (во время сна)
- ↑ Вероятность повторения действий
- ↓ Снижение порога консолидации

**Диапазон:** 0.0 – 1.0

---

#### NE (Norepinephrine) — Мобилизация / Новизна

**Источник:**
- Novelty (неожиданность > 0)
- Конфликты (conflict > 0)
- Резкие изменения

**Влияет на:**
- ↑ Увеличение exploration
- ↑ Ускорение обновления памяти
- ↑ Формирование дополнительных цепочек (во время сна)

**Диапазон:** 0.0 – 1.0

---

#### 5-HT (Serotonin) — Стабильность / Насыщение

**Источник:**
- Отсутствие конфликтов
- Повторяющиеся нейтральные исходы
- Стабилизированные паттерны

**Влияет на:**
- ↑ Повышение устойчивости паттернов
- ↓ Снижение arousal
- ↓ Замедление агрессивного обучения

**Диапазон:** 0.0 – 1.0

---

#### CORT (Cortisol) — Стресс / Перегрузка

**Источник:**
- Отрицательная награда (reward < 0)
- Высокая threat-оценка
- Конфликты без разрешения

**Влияет на:**
- ↑ Ускоренное забывание нестабильных трасс
- ↓ Подавление исследования
- ↓ Упрощение стратегий

**Диапазон:** 0.0 – 1.0

## Интеграция

### Этап 1: Инициализация в Agent

```python
# src/agent.py
from neuromodulators import NeuromodulatorState

class Agent:
    def __init__(self, ...):
        self.neuromodulators = NeuromodulatorState()  # ← инициализация
        # Подключить к sleep_manager для применения эффектов
        if self.sleep_manager:
            setattr(self.sleep_manager, "neuromodulators", self.neuromodulators)
```

### Этап 2: Обновление во время step()

```python
def step(self, context_events, ..., reward=0.0, novelty=0.0, conflict=0.0):
    # ... основная логика ...
    
    # Обновить нейромодуляторы от сигналов
    self.neuromodulators.update_from_signals(
        reward=reward, 
        novelty=novelty, 
        conflict=conflict
    )
```

### Этап 3: Применение во время sleep()

```python
# src/sleep.py
class SleepManager:
    def sleep_cycle(self):
        # ... консолидация ...
        
        # Применить эффекты нейромодуляторов
        if hasattr(self, 'neuromodulators'):
            self._apply_neuromodulators_during_sleep()
```

### Этап 4: Сохранение/Загрузка

```python
# src/storage.py
def save_agent(self, ..., neuromodulators=None):
    if neuromodulators:
        agent_state['neuromodulators'] = neuromodulators.to_dict()

def load_agent(self, ..., neuromodulators_data):
    # Восстановить нейромодуляторы
    nm = NeuromodulatorState.from_dict(neuromodulators_data)
```

## Примеры использования

### Пример 1: Базовый цикл с нейромодуляторами

```python
from agent import Agent
from neuromodulators import NeuromodulatorState

agent = Agent(hippocampus, cortex, selector, sleep_manager)

# Шаг 1: Позитивный опыт
action = agent.step(
    context=["user:hello"],
    reward=+1.0,      # Положительное подкрепление
    novelty=0.2,      # Небольшая новизна
    conflict=0.0      # Без конфликтов
)
# → DA растёт, 5-HT растёт

# Шаг 2: Неожиданное событие
action = agent.step(
    context=["user:something_unusual"],
    reward=0.0,
    novelty=0.8,      # Высокая неожиданность
    conflict=0.3
)
# → NE скачок, CORT немного растёт

# Шаг 3: Негативное событие
action = agent.step(
    context=["user:bad_thing"],
    reward=-0.5,      # Отрицательное подкрепление
    novelty=0.0,
    conflict=0.6      # Конфликт
)
# → CORT растёт, DA падает

# Консолидация со включением эффектов нейромодуляторов
stats = agent.sleep(cycles=2)
print(stats)
# Во время сна применяются эффекты:
# - DA усилит кортикальные паттерны
# - NE будет способствовать формированию цепочек
# - CORT уберёт нестабильные трассы
# - 5-HT стабилизирует существующие паттерны
```

## Эффекты во время сна

### DopamineEffect (DA > 0.05)

```python
factor = 1.0 + (da * 0.05)
for pattern in cortex.patterns:
    pattern.strength *= factor
```

**Результат:** Паттерны с высоким DA усиливаются на 5-7%

### Эффект кортизола (CORT > 0.4)

```python
threshold = forget_stability_threshold + (cortisol * 0.2)
kept = [exp for exp in hippocampus if exp.stability >= threshold ...]
```

**Результат:** При высоком CORT забывание становится агрессивнее

### Norepinephrine Effect (NE > 0.4)

```python
self._form_chains_from_recent(max_len=9)  # Увеличенное окно
```

**Результат:** Формируются более длинные и сложные цепочки

### Serotonin Effect (5-HT > 0.1)

```python
for exp in hippocampus.experiences[-50:]:
    exp.stability = min(1.0, exp.stability + serotonin * 0.01)
```

**Результат:** Опыты стабилизируются медленнее, но надёжнее

## Архитектурные решения

### 1. Почему нейромодуляторы отдельно от Affect?

| Характеристика | Affect | Neuromodulators |
|---|---|---|
| **Скорость изменения** | Быстро | Медленно |
| **Временной масштаб** | Текущий момент | Долгосрочный тренд |
| **Роль** | Управление поведением | Модуляция обучения |
| **Видимость** | Да (в GUI) | Диагностика |

### 2. Нормализация к [0, 1]

Все нейромодуляторы нормированы для:
- Единообразного влияния
- Сравнимости между собой
- Расширяемости (легко добавить новые)

### 3. Decay к базовому уровню

```python
baseline = 0.1  # Базовый фоновый уровень
# Экспоненциальный спад за ~10 секунд
```

**Цель:** Система возвращается к спокойному состоянию после стресса

## FAQ

### Q: Почему нейромодуляторы не влияют прямо на ActionSelector?

**A:** Потому что это нарушит принцип "физики без психологии". Нейромодуляторы влияют **только на консолидацию и забывание**, которые косвенно изменяют доступные паттерны и цепочки. Выбор действия остаётся детерминированным и на основе активных опытов/паттернов.

### Q: Можно ли менять параметры нейромодуляторов?

**A:** Да! Все параметры находятся в методе `update_from_signals()`:
```python
self.dopamine = self.clamp(self.dopamine + 0.2 * reward)  # 0.2 — коэффициент
```

### Q: Почему базовый уровень = 0.1?

**A:** Это обеспечивает:
- Небольшой фоновый тонус
- Быстрый спад к норме
- Разницу между низким и высоким состояниями

### Q: Как это связано с TemporalChains?

**A:** Во время сна при высоком NE формируются цепочки большей длины, что позволяет системе запоминать более длинные последовательности в неопределённые моменты.
