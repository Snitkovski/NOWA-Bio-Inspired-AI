## 2. Какие были дефекты в интерфейсе

### Дефект 1: любопытство всегда было 0.0
**Проблема:**
- Любопытство инициализировалось с 0.0
- Даже при новых сообщениях росло очень медленно
- Было сложно видеть влияние новизны

**Исправлено:**
- Любопытство теперь начинается с **0.1** (слегка поощряет исследование)
- Растет быстрее: с коэффициентом **0.4** вместо 0.25
- Теперь видно влияние новых сообщений сразу

### Дефект 2: поле цепочек было невыразительным
**Проблема:**
- Подпись «Temporal Chains» выглядела невыразительно
- Сложно было найти это поле в интерфейсе

**Исправлено:**
- Поле отображается как **«Временные цепочки»**
- Легче заметить в памяти

### Дефект 3: параметр новизны не явно использовался
**Проблема:**
- `agent.step()` принимает параметр `novelty`, но это было неочевидно
- Пользователи не знали, как передать сигнал новизны

**Исправлено:**
- Документация `TESTING_CURIOSITY.md` явно показывает, как использовать
- Примеры кода показывают передачу параметра `novelty`

## 3. Как тестировать любопытство

### Способ 1: используя интерфейс

**Шаг 1:** Откройте главное окно интерфейса

**Шаг 2:** Смотрите на **«Любопытство:»** (правая панель, аффективное состояние)

**Шаг 3:** Отправляйте сообщения:

```
Ввод: "привет"  → любопытство остается низким (повторяется)
Ввод: "привет"  → любопытство низкое
Ввод: "привет"  → любопытство низкое

Ввод: "как ты?"      → любопытство растет (новое)
Ввод: "что ты знаешь?" → любопытство растет еще больше
```

**Ожидать:**
- Новые или необычные сообщения → любопытство растет
- Одинаковые сообщения → любопытство стабильное или падает

---

### Способ 2: программный тест (рекомендуется)

**Создайте файл `test_curiosity_simple.py`:**

```python
import sys
sys.path.insert(0, 'src')

from agent import Agent
from hippocampus import NOWAHippocampus
from cortex import CortexMemory
from selector import ActionSelector
from sleep import SleepManager

# Setup
hip = NOWAHippocampus()
cortex = CortexMemory()
sel = ActionSelector(actions=['say', 'ask', 'listen'])
sleep_mgr = SleepManager(hip, cortex)
agent = Agent(hip, cortex, sel, sleep_manager=sleep_mgr)

print("=" * 50)
print("TEST: Curiosity with Novelty")
print("=" * 50)

# Test 1: Повторяющиеся сообщения (низкая новизна)
print("\n1. ПОВТОРЯЮЩИЕСЯ (низкая новизна):")
for i in range(3):
    agent.step(["user:hello"], novelty=0.0)
    print(f"   Шаг {i+1}: curiosity = {agent.affect_state.curiosity:.2f}")

# Test 2: НОВЫЕ сообщения (высокая новизна)
print("\n2. НОВЫЕ (высокая новизна):")
for i in range(3):
    agent.step(["user:new"], novelty=0.8)
    print(f"   Шаг {i+1}: curiosity = {agent.affect_state.curiosity:.2f}")

print("\n" + "=" * 50)
print("РЕЗУЛЬТАТ:")
print(f"Curiosity стартовал с 0.1 (базовое исследование)")
print(f"Curiosity вырос до {agent.affect_state.curiosity:.2f} при высокой новизне")
print("=" * 50)
```

**Запуск:**
```bash
python test_curiosity_simple.py
```

**Ожидаемый результат:**
```

1. ПОВТОРЯЮЩИЕСЯ (низкая новизна):
   Шаг 1: curiosity = 0.10

   Шаг 3: curiosity = 0.10

2. НОВЫЕ (высокая новизна):
   Шаг 1: curiosity = 0.42
   Шаг 2: 0.66

==================================================
РЕЗУЛЬТАТ:
Curiosity стартовал с 0.1 (базовое исследование)
```

## 4. Почему не получалось раньше

### Распространенные ошибки:

#### Ошибка 1: не передавать параметр новизны
```python
# НЕПРАВИЛЬНО — novelty по умолчанию 0.0
agent.step(["user:hello"])

# ПРАВИЛЬНО — явно передать novelty
agent.step(["user:hello"], novelty=0.8)
```

#### Ошибка 2: ожидать любопытство без сна
```python
# НЕПРАВИЛЬНО
# Отправить несколько сообщений
# Любопытство поднялось... но цепочки не формируются

# ПРАВИЛЬНО
# Отправить несколько сообщений
agent.sleep(cycles=3)  # ← Сон для консолидации цепочек
# Теперь цепочки сформированы
```

#### Ошибка 3: ждать много цепочек от одного сообщения
```python
# НЕПРАВИЛЬНО
agent.step(["user:hello"], novelty=0.8)
agent.sleep(cycles=1)
print(sleep_mgr.chain_memory.statistics())
# total_chains: 0  ← Одного сообщения недостаточно

# ПРАВИЛЬНО
# Отправить несколько РАЗНЫХ сообщений
for msg in ["hello", "how are you?", "what's up?"]:
    agent.step([f"user:{msg}"], novelty=0.8)

agent.sleep(cycles=1)
print(sleep_mgr.chain_memory.statistics())
# total_chains: 5+  ← Много цепочек из разных контекстов
```

- [ ] При новых сообщениях любопытство должно **расти**
- [ ] Цепочки должны быть **в памяти** после сна
- [ ] Тесты должны **проходить** (`pytest -q`)
