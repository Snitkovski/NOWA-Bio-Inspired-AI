## 2. Ключевые изменения

### 2.1 Критичное: добавление habit_strength в формулу Net

**Файл:** `src/basal_ganglia.py` — метод `choose()`

**Проблема согласно спецификации:**
> «Сила привычки не участвует в выборе»
> «Сейчас привычки обучаются, но не влияют на Net»

**Решение:**
```python
# КРИТИЧНОЕ ДОБАВЛЕНИЕ: habit_strength усиливает привычку в выборе
# HABIT_GAIN=0.3 контролирует силу влияния привычки на Net
# Это позволяет привычке увеличивать вероятность выбора, но не гарантировать его
habit_gain = 0.3
net += channel.habit_strength * habit_gain
```

**Эффект:**
- Привычки теперь влияют на выбор действия
- habit_strength ∈ [0..1] усиливает Net на величину до 0.3
- Это позволяет успешно обученным привычкам доминировать в выборе
- Баланс: привычка важна, но не абсолютна (коалиция дофамина, префронтальной коры и прочих факторов может переопределить её)

## 5. Технические детали

### Формула Net (обновлённая)

```
Go_signal = go_weight × (1 + DA_mod) × (1 + affect_mod)
NoGo_signal = nogo_weight × (1 + CORT_mod)
Net = Go_signal - 0.5 × NoGo_signal
Net += PFC_pressure × wakefulness_modifier
Net += habit_strength × 0.3  [НОВОЕ]
```

### Коэффициенты

| Параметр | Значение | Назначение |
|----------|----------|-----------|
| HABIT_GAIN | 0.3 | Сила влияния привычки на выбор |
| Множитель NoGo | 0.5 | Мягкость конкуренции (NoGo не полностью подавляет) |
| Модификатор бодрствования | sqrt(wakefulness) | Ослабление влияния префронтальной коры |
| Диапазон температуры | [0.1 .. 3.0] | Управление энтропией исследования |

### Инварианты

- go_weight, nogo_weight и habit_strength лежат в [0..1] (автоматическое ограничение)
- habit_strength усиливает, но не гарантирует выбор
- Префронтальная кора может быть проигнорирована (давление не обязательно)
- Нейромодуляторы ожидаются нормализованными
- Обучение исключительно во сне (нет обучения в бодрствовании)

## 10. Использование в коде

```python
from src.agent import Agent

agent = Agent()

# Регистрировать действия
agent.register_action_channel("attack", go_weight=0.8, nogo_weight=0.2)
agent.register_action_channel("defend", go_weight=0.5, nogo_weight=0.5)

# Выбор (теперь с учетом привычек)
action = agent.choose_action_via_basal_ganglia(pfc_pressure=1.0)

# Запись результата
agent.record_action_outcome(action, success=True, dopamine=1.5)

# Во сне — обучение и консолидация привычек
agent.sleep()  # apply_sleep_learning() + consolidate_habits()
```

**Ключевой момент:** после успешного повторения действия привычка (`habit_strength`) будет расти, и это действие будет чаще выбираться в будущем, даже без дополнительного дофамина.
