   - Класс `WakefulnessState` с физиологическим состоянием [0.0..1.0]
   - Накопление усталости: 16 часов → полное истощение (1.0)

   - Методы обновления: `update_waking()`, `update_sleeping()`
   - Методы интеракции: `get_neuromodulator_deltas()`, `get_pfc_signal_strength_modifier()`, `get_cognitive_reliability()`

2. **Модуляция Нейромодуляторов**
   - Кортизол: ↑ Повышается с усталостью (стресс-индуцированное состояние)
   - Норадреналин: ↑ Повышается с усталостью (попытка бодрствования)
   - Серотонин: ↓ Понижается с усталостью (потеря стабильности)
   - При сне: значения восстанавливаются к норме

3. **Модуляция PFC (Префронтальная кора)**
   - Сила сигнала: деградирует от 1.0 до 0.6 с полной усталостью
   - Уровень шума: увеличивается от 1.0 до 1.7 с полной усталостью

4. **GUI Интеграция - Управление Сном**
   - Новая боковая панель "😴 Состояние бодрствования" с визуальным индикатором
   - Три кнопки сна: 💤 30мин (1 цикл), 😴 1ч (2 цикла), 😪 3ч (6 циклов)
   - Диалог консолидации сна с автоматическими пресетами циклов
   - Параметры для отслеживания: уровень усталости, надёжность когнитивных функций, время последнего сна
   - Удаление дублирующейся кнопки сна (консолидация UI)

## 🚀 Как Использовать

### Запуск GUI

```bash
cd e:\git\NOWA-Cognitive
python src/gui.py
```

### Запуск Демонстрации Wakefulness (НОВОЕ)

```bash
cd e:\git\NOWA-Cognitive
python wakefulness_demo.py
```

Показывает 24-часовой цикл сна и бодрствования с модуляцией нейромодуляторов.

### Наблюдение за Аффективным Состоянием

1. Напишите сообщение в поле ввода
2. Нажмите кнопку "📤 Отправить"
3. Смотрите, как обновляются индикаторы в реальном времени:
   - 🟢 Валентность меняет цвет (красный → зелёный)
   - 🟠 Возбуждение отражает уровень активации
   - 🔴 Угроза появляется при конфликтах
   - 🟣 Любопытство растёт при новизне

### Управление Сном Агента (НОВОЕ в v2.1)

1. **Мониторьте усталость** в боковой панели "😴 Состояние бодрствования"
2. **Нажмите кнопку сна**, когда необходимо:
   - 💤 **Быстрый сон (30м)** - для слабо уставшего агента
   - 😴 **Обычный сон (1ч)** - для среднего уровня усталости
   - 😪 **Долгий сон (3ч)** - для критического истощения
3. **Диалог консолидации** откроется с автоматическими пресетами циклов
4. **Смотрите результаты** - усталость упадёт, способности восстановятся

### Оценка Результата

1. Выберите оценку (-2 "очень плохо" до +2 "отлично")
2. Нажмите "💾 Сохранить отзыв"
3. Смотрите, как валентность изменяется в ответ на оценку
4. Наблюдайте обновление статуса готовности

### Анализ Состояния

1. Нажмите вкладку "❤️ Аффективное состояние" в Инспекторе
2. Прочитайте детальный операционный анализ
3. Посмотрите ограничивающие и поддерживающие факторы
4. Проверьте паттерны регуляции

## 💾 Ключевые Параметры Аффективного Состояния

| Параметр | Диапазон | Цвета | Значение |
|----------|----------|-------|----------|
| **Валентность** | -1.0 ÷ +1.0 | Красный → Зелёный | Уровень удовлетворённости |
| **Возбуждение** | 0.0 ÷ 2.0 | Голубой → Оранжевый | Уровень активации |
| **Угроза** | 0.0 ÷ 1.0 | Зелёный → Красный | Уровень нестабильности |
| **Любопытство** | 0.0 ÷ 1.0 | Серый → Фиолетовый | Стремление исследовать |
| **Готовность** | 0.0 ÷ 1.0 | Вычисляемое | Готовность к обучению |

| Параметр | Диапазон | Значение |
|----------|----------|----------|
| **Уровень усталости** | 0.0 ÷ 1.0 | Физиологическое состояние (0=отдохнул, 1=полностью истощён) |
| **Накопление** | 16 часов | Время для полного истощения (0 → 1.0) |
| **Восстановление от сна** | 8 часов | Время полного восстановления (1.0 → 0) |

| **Модулятор PFC шума** | 1.0 ÷ 1.7 | Увеличение шума с усталостью |
