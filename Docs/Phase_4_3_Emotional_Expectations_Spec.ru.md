# 1. Назначение

Фаза 4.3 вводит предсказательный слой над эмоциональной историей.

Этот слой:
- оценивает вероятные будущие эмоциональные тенденции;
- определяет направление тренда (рост / спад / устойчивость);
- выявляет риск устойчивости навязчивых паттернов;
- порождает вероятностные нарративные прогнозы.

Этот слой не должен:
- изменять семантические эмоции;
- изменять оси аффективного пространства;
- влиять на выбор действия или планирование;
- подкреплять собственные предсказания.

Это только слой прогнозирования.

# 5. Основные алгоритмы

## 5.1 Обнаружение тренда

Для каждой эмоции:

1. Вычислить взвешенную раннюю активацию.
2. Вычислить взвешенную недавнюю активацию.
3. `delta = recent_mean - early_mean`

Пороги:
- `delta > +0.1` → рост (`increasing`)
- `delta < -0.1` → спад (`decreasing`)
- иначе → устойчивость (`stable`)

------------------------------------------------------------------------

## 5.2 Оценка вероятности

Базовая вероятность:

`probability = 0.4 + 0.6 * inertia`

где `inertia` выводится из паттернов фазы 4.2.

Поправки:
- если рост → +0.1
- если спад → −0.1
- ограничить интервалом [0, 1]

------------------------------------------------------------------------

## 5.3 Перенос навязчивости

Если:
- `pattern.obsessive == True`
- `inertia >= 0.6`

Тогда:
- `risk_of_repetition = True`
- `probability >= 0.8`

------------------------------------------------------------------------

## 5.4 Продолжение направления

Если фаза 4.2 обнаружила смену направления:
- увеличить вероятность новой доминирующей эмоции;
- уменьшить вероятность прежней доминирующей эмоции.

------------------------------------------------------------------------

## 5.5 Общий прогноз

Вычислить дисперсию активации по недавним эпизодам.

Если дисперсия низкая и инерция высокая → `"stabilizing"`  
Если доминирование быстро чередуется → `"volatile"`  
Если тренд монотонного роста → `"escalating"`

------------------------------------------------------------------------

# 6. Правила нарративного прогноза

Примеры:

- «Вероятно сохранится радость.»
- «Наблюдается тенденция к усилению страха.»
- «Эмоциональная динамика стабилизируется.»
- «Существует риск повторения навязчивого паттерна.»

Язык обязан оставаться вероятностным и никогда не быть детерминированным.

------------------------------------------------------------------------

# 7. Анти-паттерны

### 7.1 Самоисполняющееся пророчество

Предсказания не должны изменять эмоциональные слои.

### 7.2 Детерминированный язык

Никогда не использовать абсолютную уверенность.

### 7.3 Чрезмерная реакция на шум

Один эпизод не должен порождать тренд.

### 7.4 Допущение вечной устойчивости

Высокая инерция не равна постоянству.

### 7.5 Загрязнение обратной связью

Ожидания не должны возвращаться в память как события.

------------------------------------------------------------------------

# 8. Тест-кейсы

## 8.1 Устойчивая радость

Эпизоды: радость, радость, радость  
Ожидается:
- тренд: `stable` или `increasing`
- вероятность > 0.6

------------------------------------------------------------------------

## 8.2 Сдвиг от печали к радости

Раннее: доминирует печаль  
Недавнее: доминирует радость  
Ожидается:
- радость растёт
- печаль спадает

------------------------------------------------------------------------

## 8.3 Навязчивый страх

Страх повторяется при высокой инерции  
Ожидается:
- `risk_of_repetition = True`
- вероятность >= 0.8

------------------------------------------------------------------------

## 8.4 Высокая вариативность

радость → печаль → страх → радость  
Ожидается:
- низкая уверенность
- `global_outlook = volatile`

------------------------------------------------------------------------

## 8.5 Недостаточные данные

Меньше минимально требуемого числа эпизодов  
Ожидается:
- пустой список ожиданий
- нейтральный прогноз

------------------------------------------------------------------------
