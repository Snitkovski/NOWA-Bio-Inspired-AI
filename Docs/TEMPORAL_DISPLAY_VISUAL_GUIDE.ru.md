## Примеры формата данных

### T0 — текущее мгновенное состояние
```
T0 (Мгновение):
val:+0.25 arl:+0.42 thr:+0.10 cur:+0.33

Интерпретация:
- Положительная валентность (0.25): агент в хорошем настроении
- Высокое возбуждение (0.42): агент активен и насторожен
- Низкая угроза (0.10): не испуган
- Среднее любопытство (0.33): несколько заинтересован
```

### T1 — краткосрочный тренд (окно из 10 элементов)
```
T1 (Тренд):
val:+0.08 arl:+0.15 thr:-0.03 cur:+0.12

Интерпретация:
- Среднее T1 на 0.08 выше T0 (0.17 против 0.25)
- Показывает, становится ли агент счастливее (+) или печальнее (-)
- Тренд показывает направление эмоционального движения
- Окно заполняется от 0/10 до 10/10 по мере шагов агента
```

### T2 — консолидированная среднесрочная базовая линия
```
T2 (базовая линия, медленный дрейф):
val:+0.12 arl:+0.38 thr:+0.06 cur:+0.22

Интерпретация:
- Устойчивое опорное состояние после консолидации
- Представляет «выученное» базовое эмоциональное состояние
- Медленный дрейф во время бодрствования (микроконсолидация)
- Усиливается во время консолидации сна
- Обычно менее крайнее, чем T0 (сглажено)
```

### T3 — долгосрочный аттрактор
```
T3 (Аттрактор):
val:+0.10 arl:+0.35 thr:+0.07 cur:+0.20

Интерпретация:
- Очень устойчивая «личность» агента
- Возникает после многих циклов сна
- Представляет долгосрочное поведенческое смещение
- Редко меняется (очень медленная эволюция)
```

## Примеры поведения в реальном времени

### Пример 1: положительная обратная связь
```
Шаг 1: пользователь хвалит агента
  T0: val:+0.15, arl:+0.30, cur:+0.25
  
Шаг 2: агент обрабатывает похвалу
  T0: val:+0.35 (счастье выросло)
  Среднее T1: +0.25 (тренд положителен)
  
Шаг 3: ещё положительные взаимодействия
  T0: val:+0.42 (пик счастья)
  Среднее T1: +0.32 (тренд продолжает расти)
  Окно T1: 8/10 (заполняется)
```

### Пример 2: обнаружена угроза
```
Шаг 1: упомянут конфликт
  T0: threat:+0.05, arl:+0.35
  
Шаг 2: агент истолковывает это как угрозу
  T0: threat:+0.45 (страх вызван)
  T0: arl:+0.65 (возбуждение подскочило)
  
Шаг 3: разрешение
  T0: threat:+0.15 (страх снижается)
  T0: arl:+0.40 (возбуждение нормализуется)
  Среднее T1 показывает всю траекторию
```

### Пример 3: после консолидации сна
```
До сна:
  T0: val:+0.30, arl:+0.50 (неустойчиво)
  Среднее T1: +0.25, +0.45 (скачет)
  T2: val:+0.15, arl:+0.35 (старая базовая линия)
  T3: val:+0.10, arl:+0.30 (старый аттрактор)

После сна (2 цикла):
  T0: val:+0.25, arl:+0.42 (нормализовано)
  Среднее T1: +0.22, +0.40 (сглажено)
  T2: val:+0.22, arl:+0.40 (обновлено)
  T3: val:+0.18, arl:+0.35 (сдвинуто к положительному)
  
Итог: агент научился быть немного счастливее и более возбуждённым
```

## Отладка по временному отображению

### Проблема: агент застревает в отрицательном состоянии
```
Диагноз по временному отображению:
T0:  val:-0.80 (очень печален)
T1:  val:-0.75 (тренд отрицательный)
T2:  val:-0.60 (базовая линия печальна)
T3:  val:-0.55 (аттрактор тянет к печали)

Решение:
- Провести положительные взаимодействия, чтобы сдвинуть T0 вверх
- Консолидация сна постепенно поднимет T2 и T3
- Эмоциональную личность агента можно переформировать
```

### Проблема: беспорядочное поведение
```
Диагноз:
T0:  меняется: +0.8, -0.6, +0.4, -0.3 (скачет)
T1:  среднее: +0.05 (сильно отличается от T0)
Окно T1: 4/10 (недостаточно истории)

Решение:
- Агент ещё не накопил достаточно опыта
- Дать ему больше взаимодействий, чтобы заполнить окно T1
- Дать консолидации сна стабилизировать паттерны
```

### Проблема: обучение не работает
```
Диагноз:
T0: меняется во время бодрствования (хорошо)
T1: накапливается (хорошо)
T2: НЕ обновляется после сна
T3: НЕ обновляется после сна

Решение:
- Проверить циклы консолидации sleep_manager
- Убедиться, что вызывается temporal.sleep()
- Обеспечить не менее 2 циклов сна для действенной консолидации
```

## Цветовые указатели

| Уровень | Цвет | Смысл |
|-------|-------|---------|
| T0 | Синий | Текущее непосредственное состояние |
| T1 | Бирюзовый | Тренд (что происходит) |
| T2 | Фиолетовый | Базовая линия (чем должно быть) |
| T3 | Красный | Аттрактор (чему отдаётся предпочтение) |
| Панель | Светло-синий | Визуальная группировка |

## Когда обновляется каждый уровень

| Уровень | Обновляется при | Частота |
|-------|-----------|-----------|
| T0 | Agent.step() | Каждое взаимодействие |
| T1 | Agent.step() | Каждое взаимодействие (очередь) |
| T2 | Agent.step() и Agent.sleep() | Дрейф бодрствования и консолидация |
| T3 | Agent.sleep() | Только во время глубокой консолидации |

## Указатель окна (T1)

```
Окно T1: 0/10  → только начато, собран 1 снимок
Окно T1: 5/10  → окно заполнено наполовину, 5 снимков
Окно T1: 10/10 → полное окно, 10 снимков (максимум)
Окно T1: 10/10 → после 10 и далее самый старый продолжает заменяться
```

Окно T1 хранит 10 самых недавних снимков аффекта. Полное окно (10/10) означает, что данных тренда достаточно.
