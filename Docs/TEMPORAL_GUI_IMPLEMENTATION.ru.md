## Цель выполнена
В графический интерфейс NOWA добавлена полная визуализация временных уровней, показывающая четырёхъярусную временную архитектуру (T0/T1/T2/T3) для отладки и изучения паттернов поведения агента во времени.

## Что добавлено

### 1. Новая панель интерфейса — «Временные уровни»
**Расположение**: правая панель, после отображения аффективного состояния
**Размер**: 7 строк отображения и индикатор окна

**Компоненты**:
- **T0 (мгновение)** — мгновенное состояние
  - Текущие значения аффекта: валентность, возбуждение, угроза, любопытство
  - Обновляется на каждом шаге агента

- **T1 (тренд)** — краткосрочный тренд (окно из 10 элементов)
  - Показывает дельты относительно T0 со знаками плюс и минус
  - Выявляет временное направление изменений аффекта
  - Индикатор заполнения окна (x/10)

- **T2 (базовая линия)** — консолидированный среднесрочный ориентир
  - Медленный дрейф во время бодрствования (микроконсолидация)
  - Стабилизируется при консолидации во сне
  - Ориентир для измерения дрейфа

- **T3 (аттрактор)** — долговременные аттракторы поведения
  - Очень медленная эволюция
  - Представляет выученное эмоциональное смещение личности

### 2. Метод обновления — `update_temporal_display()`
**Расположение**: `src/gui.py`, строки 430–471
**Интеграция**: вызывается из:
- `process_input()` после каждого взаимодействия с пользователем (строка 495)
- обратного вызова консолидации сна (строки 1317–1318)

**Свойства**:
- Извлекает данные из `agent.temporal.get_levels()`
- Форматирует T0 как абсолютные значения
- Форматирует T1 как относительные дельты
- Показывает состояние заполнения окна
- Корректно обрабатывает ошибки

### 3. Визуальная интеграция
- Цветовая кодировка для визуального слежения:
  - T0 (синий): текущее состояние
  - T1 (бирюзовый): краткосрочный тренд
  - T2 (фиолетовый): консолидированная базовая линия
  - T3 (красный): долговременные аттракторы
- Светло-голубой фон (#f0f8ff) для визуального отделения

## Как это работает

### Фаза бодрствования (`Agent.step()`)
```
Agent.step(context)
  → temporal.log(snapshot)        # T0 created
  → temporal.t1.append(snapshot)  # T1 window updated (micro-consolidation when full)
  → GUI.process_input()
    → update_temporal_display()   # Display updated
```

### Фаза сна (`Agent.sleep()`)
```
Agent.sleep(cycles=N)
  → temporal.sleep()              # T1→T2, T2→T3 consolidation
  → sleep_manager updates affect_state from temporal
  → GUI displays update
    → update_temporal_display()   # T2/T3 now visible
```

## Использование и польза

### Для отладки:
1. **Застревание поведения**: проверить T3 — смещены ли аттракторы?
2. **Волатильность**: проверить дельты T1 — высокая дисперсия означает неустойчивость
3. **Обучение**: проверить дрейф T2 во время бодрствования и обновление T2/T3 после сна
4. **Личность**: аттракторы T3 показывают выученный эмоциональный профиль

### Для исследования:
1. **Наблюдение в реальном времени** за эволюцией аффективного состояния
2. **Временные паттерны**, видимые на нескольких масштабах (T0/T1/T2/T3)
3. **Эффекты консолидации**, видимые сразу после сна
4. **Атрибуция поведения** — понимание, почему агент действует определённым образом

## Опыт пользователя

При использовании интерфейса:
1. Появляется новая панель «Временные уровни»
2. Значения T0 меняются с каждым шагом
3. Окно T1 заполняется от 0/10 до 10/10
4. T2 дрейфует во время бодрствования и стабилизируется после сна
5. Аттракторы T3 возникают после нескольких циклов сна
6. Это показывает эмоциональное состояние агента на разных временных масштабах

Эта визуализация помогает понять, как аффективное состояние агента эволюционирует и консолидируется во времени, то есть увидеть жизнь агента во временном измерении.
