## Архитектура

### До рефакторинга
```
Waking: User Input → Agent Step → (Learning!) → Weight Updates
        Feedback ----→ Selector.learn() → Direct Weight Optimization
Result: ML/RL style system
```

### После рефакторинга
```
Waking: User Input → Agent Step → Store Experience (immutable)
        Feedback → Intensity (0.2-1.0) → Wait for sleep
                                              ↓
Sleep:  Experiences → Cluster → Consolidate → Patterns → Cortex
        No direct weight optimization!
                                              ↓
Result: Behavior emerges from consolidated memories (neuroscience-inspired)
```

## Проверка основного принципа NOWA

**Проверка:** «Если селектор заморожен и агент получает новый опыт, изменится ли поведение?»

**Ответ:** **да** — через консолидацию во сне:

1. Новые опыты → гиппокамп (неизменяемое хранение)
2. У селектора нет весов (его нельзя «заморозить» обучением)
3. Сон консолидирует → создаёт семантические паттерны
4. Выбор использует активацию гиппокампа и паттерны
5. Поведение возникает из консолидации, а не из оптимизации

**Подтверждение в интерфейсе:**
- Селектор: нет атрибута `weights`, нет метода `learn()`
- Обучение: целиком в `SleepManager` (только консолидация)
- Паттерны: появляются только после сна
- Циклы: счётчик растёт с консолидацией
