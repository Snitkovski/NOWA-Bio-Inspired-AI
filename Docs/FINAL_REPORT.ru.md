## Архитектурные улучшения

### До

```
Agent → Selector → Действие
           ↓
      (статичное выбор)
```

### После

```
Agent.step(reward, novelty, conflict)
    ↓
Обновить affect_state
    ↓
Selector(affect_modifier=1.2)
    ↓
Действие + Переоценка привычек
    ↓
Self-reflection via SelfModel
```

### Новые возможности

1. **Адаптивное поведение** — действия зависят от состояния
2. **Гибкие привычки** — динамическая переоценка
3. **Саморефлексия** — система описывает себя (без антропоморфизма)
4. **Консистентность** — все параметры в границах
5. **Прозрачность** — операциональные метрики доступны

## Как использовать

### Базовое использование

```python
from agent import Agent
from affect import AffectiveState

# Agent автоматически инициализирует AffectiveState
agent = Agent(hippocampus, cortex, selector, intent_memory=memory)

# Обновления с сигналами окружения
action = agent.step(
    context_events=["situation"],
    reward=0.8,           # Положительный исход
    novelty=0.3,          # Неожиданность
    conflict=0.1          # Обнаружено ли противоречие
)

# Проверить состояние
state = agent.get_state()
print(f"Current valence: {state['affect_state']['valence']}")
```

### Саморефлексия

```python
from self_model import SelfModel

model = SelfModel(agent)

# Полный отчет о состоянии
report = model.introspect()

# Операциональное описание (БЕЗ эмоций!)
description = model.describe_operational_state()
# Output: "SystemState(valence=0.45, arousal=0.82, threat=0.12, ...)"

# Анализ готовности к изменениям
readiness = model.get_regulatory_readiness_report()
```

## Принцип работы

### Цикл адаптации

1. **Восприятие** — Agent.step() получает сигналы (reward, novelty, conflict)
2. **Регуляция** — аффективное состояние обновляется на основе сигналов
3. **Адаптация** — Selector использует модификатор для изменения выбора
4. **Консолидация** — IntentMemory переоценивает привычки
5. **Саморефлексия** — SelfModel описывает текущее состояние

### Ограничения (гарантии)

- Субъективный язык никогда не используется
- Все параметры остаются в границах
- Система полностью детерминирована
- Нет случайного фактора в управлении (только в выборе действий)
