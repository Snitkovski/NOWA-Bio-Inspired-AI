## Область

`src/genome.py` реализует эволюционируемое представление генома для агентов NOWA. Модуль автономен и использует только стандартную библиотеку Python.

Основные цели:
1. детерминированный порядок генов и воспроизводимые операции при фиксированном генераторе случайных чисел
2. ограниченные числовые диапазоны для каждого гена
3. средства мутации и кроссовера для эволюционных процедур
4. преобразование в словари параметров уровня модуля для построения агента

## Реализованные объекты

### `GeneDescriptor`

Метаданные одного гена:
- `key`
- `module`
- `min_val`, `max_val`
- `default`
- `sigma`
- `description`

Проверка выполняется при создании дескриптора (`min < max`, `default` в диапазоне, `sigma > 0`).

### `GENE_REGISTRY`

Детерминированный упорядоченный реестр генов, сгруппированный по префиксу:
- `NM` (нейромодуляторы)
- `AF` (аффективное пространство)
- `WK` (бодрствование и циркадный ритм)
- `DR` (автономные драйвы)
- `LR` (обучение и память)
- `IM` (воображение)
- `LT` (продолжительность жизни и время)

Заметное добавление DR для интеграции с роем:
- `dr_perception_radius_factor` (диапазон `0.5..2.0`, по умолчанию `1.0`)

### `GenomeVector`

Основные методы:
- создание: `default()`, `random(rng)`, `from_dict(data)`, `from_array(array, generation=0)`
- преобразования: `mutate(rate, sigma_scale, rng)`, `crossover(other, alpha, mode, rng)`
- метрики: `distance(other)`, `similarity(other)`, `summary()`, `validate()`
- сериализация: `to_dict()`, `to_array()`
- развёртка: `to_agent_params()`

Поддерживаемые режимы кроссовера:
- `arithmetic`
- `uniform`
- `sbx` (eta=2)

## Контракты сериализации

### `to_dict()`

Возвращает:

```python
{
    "version": "1.0",
    "generation": int,
    "lineage_id": str,
    "genes": {key: value, ...},
}
```

### `from_dict()`

- игнорирует неизвестные ключи генов
- заполняет отсутствующие ключи значениями по умолчанию
- ограничивает значения вне диапазона границами дескриптора (с предупреждением)

### Круговой проход массива

- `to_array()` сохраняет порядок реестра
- `from_array()` требует точную длину, иначе возбуждает `ValueError`

## Развёртка параметров агента

`GenomeVector.to_agent_params()` разворачивает гены в блоки конфигурации модулей:
- `affective_space`
- `wakefulness`
- `neuromodulators`
- `autonomous`
- `value_layer`
- `hippocampus`
- `sleep`
- `imagination`
- `mortality`

Отображение, связанное с роем:
- `autonomous.perception_radius_factor <- dr_perception_radius_factor`

Отображение, связанное со смертностью:
- `mortality.max_lifespan_factor <- lt_max_lifespan_factor`

Это отображение предназначено для конвейеров инициализации агента в стиле фабрики.

## Детерминизм и безопасность

1. Все стохастические операции принимают внешний `random.Random`.
2. Фиксированное зерно генератора даёт детерминированные результаты мутации и кроссовера.
3. Все обновления генов ограничиваются биологически ограниченными диапазонами.
4. Метрика расстояния — нормализованное евклидово расстояние в `[0.0, 1.0]`.
