## Краткое изложение

В графическом интерфейсе NOWA реализована визуализация временных уровней, показывающая четырёхъярусную временную архитектуру (T0/T1/T2/T3) для отладки и понимания поведения агента во времени.

**Запрос пользователя**: «Внеси ещё изменения в графический интерфейс... чтобы была видна его жизнь в разрезе времени»

**Статус**: ЗАВЕРШЕНО И ПРОТЕСТИРОВАНО

## Разбор возможностей

### T0 — мгновенное состояние
- **Что**: снимок текущего аффекта
- **Обновление**: на каждом `agent.step()`
- **Показывает**: валентность, возбуждение, угрозу, любопытство (абсолютные значения)
- **Назначение**: видеть непосредственное эмоциональное состояние

### T1 — краткосрочный тренд
- **Что**: скользящее окно из 10 элементов
- **Обновление**: на каждом `agent.step()` (накопление)
- **Показывает**: средние значения и дельты относительно T0 (индикаторы ±)
- **Назначение**: обнаруживать эмоциональную траекторию
- **Индикатор**: окно T1: x/10 (заполненность окна)

### T2 — консолидированная базовая линия
- **Что**: среднесрочный ориентир
- **Обновление**: во время консолидации сна
- **Показывает**: устойчивую базовую линию после обучения
- **Назначение**: понимать «усвоенное» эмоциональное состояние

### T3 — долгосрочные аттракторы
- **Что**: очень медленная эволюция
- **Обновление**: во время консолидации глубокого сна
- **Показывает**: долгосрочное поведенческое смещение
- **Назначение**: наблюдать складывающуюся личность

## Отладка с помощью временного отображения

### Проблема 1: агент застрял в отрицательном состоянии
```
Диагноз:
  T0:  val:-0.80 (сильно отрицательно)
  T1:  val:-0.75 (тренд отрицательный)
  T2:  val:-0.60 (базовая линия отрицательна)
  T3:  val:-0.55 (личность смещена вниз)

Решение:
  1. Дать положительный опыт
  2. Наблюдать рост тренда T1
  3. Уложить спать для консолидации
  4. T2/T3 сдвигаются в положительную сторону
```

### Проблема 2: неустойчивое поведение
```
Диагноз:
  T0: скачки: +0.8, -0.6, +0.4 (неустойчиво)
  T1: среднее: +0.05 (сильно отличается)
  Окно: 3/10 (истории недостаточно)

Решение:
  1. Больше взаимодействий, чтобы заполнить окно
  2. Сон, чтобы сгладить паттерны
  3. Базовая линия T2 даёт устойчивость
```

### Проблема 3: обучение не работает
```
Диагноз:
  T0: меняется во время взаимодействий
  T1: накапливается
  T2: НЕ обновляется после сна
  T3: НЕ обновляется после сна

Решение:
  1. Проверить sleep_manager.consolidation_cycles
  2. Убедиться, что вызывается temporal.sleep()
  3. Обеспечить cycles >= 2 для консолидации
```

## Интеграция в архитектуру

### Поток данных системы
```
┌─────────────────┐
│  Ввод пользователя │
└────────┬────────┘
         ↓
┌─────────────────┐
│  Agent.step()   │
└────────┬────────┘
         ↓
    ┌─────────────────────────┐
    │  temporal.log(snapshot) │
    │  ├─ T0 = текущее        │
    │  └─ T1.append(snapshot) │
    └────────┬────────────────┘
             ↓
    ┌──────────────────────────┐
    │  GUI.process_input()     │
    │  → update_affect_display │
    │  → update_temporal_display ← НОВОЕ
    │  → update_memory_display │
    └─────────────────────────┘
             ↓
    ┌──────────────────────────┐
    │  Отображение обновлено   │
    │  (видны T0/T1)           │
    └─────────────────────────┘

Фаза сна:
┌──────────────────┐
│  Agent.sleep()   │
└────────┬─────────┘
         ↓
    ┌──────────────────────────┐
    │  temporal.sleep()        │
    │  ├─ T1 → T2 (консол.)    │
    │  └─ T2 → T3 (аттрактор)  │
    └────────┬─────────────────┘
             ↓
    ┌──────────────────────────┐
    │  Обратный вызов сна GUI  │
    │  → update_temporal_display ← НОВОЕ
    └────────┬─────────────────┘
             ↓
    ┌──────────────────────────┐
    │  Отображение обновлено   │
    │  (теперь видны T2/T3)    │
    └─────────────────────────┘
```
