# Порядок чтения

English version: [START_HERE_NEW.en.md](START_HERE_NEW.en.md)

Настоящий текст задаёт порядок чтения комплекса NOWA. Он заменяет прежние обзорные указатели с промежуточными сводками тестов.

1. [SCIENTIFIC_DESCRIPTION.ru.md](SCIENTIFIC_DESCRIPTION.ru.md) — предмет, слои, инварианты, четыре экспериментальные установки. Английский текст вынесен в отдельный файл.
2. [arxiv_NOWA_ru.md](arxiv_NOWA_ru.md) либо [arxiv_NOWA_en.md](arxiv_NOWA_en.md) — формализация, уравнения и разбор колонии.
3. Научное описание той установки, которая является предметом работы:
   - колония: [COLONY_SPEC.ru.md](../Demo/Colony%20chinchillas/Docs/COLONY_SPEC.ru.md);
   - этологический агент: [SCIENTIFIC_DESCRIPTION.ru.md](../Demo/Tamagochi%20Chinchilla/Docs/SCIENTIFIC_DESCRIPTION.ru.md);
   - виртуальная организация: [SCIENTIFIC_DESCRIPTION.ru.md](../Demo/Virtual%20company/Docs/SCIENTIFIC_DESCRIPTION.ru.md);
   - лексические нормы: [SCIENTIFIC_DESCRIPTION.ru.md](../Demo/Warriner%20Validation/Docs/SCIENTIFIC_DESCRIPTION.ru.md).
4. Нормативная спецификация модуля, если изменяется контракт реализации.
5. [API.md](API.ru.md) и [TESTING.ru.md](TESTING.ru.md) — интерфейс и протоколы проверки ядра.

Воспроизведение ядра описано в [README.md](../README.md).
