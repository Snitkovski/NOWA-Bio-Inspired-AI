## Общая цель

Разработать когнитивную архитектуру, включающую:

- Нечёткий гиппокамп (подобный CA3/CA1)
- Корковый слой стратегий (политика на логитах)
- Выбор действия, модулируемый драйвами
- Непрерывную эмоциональную регуляцию
- Конфликт и арбитраж (подобный ACC)
- Дофаминовое обучение временной разности (актёр–критик)
- Внешнюю сенсорную интеграцию
- Конвейер консолидации

## Фаза 1 (месяцы 1–2) — Hippocampus 2.0: дополнение паттерна и новизна

### 1.1 Цели

- Убрать точное совпадение
- Реализовать нечёткое извлечение
- Добавить обнаружение новизны
- Ввести контекстно-временное кодирование

### 1.2 Исследовательские задачи

#### A. Нечёткое извлечение по сходству

Метрика:

```
similarity = jaccard(signature_A, signature_B)
```

Эксперименты:

- Точность извлечения при частичном входе (20–60% отсутствующих признаков)
- Частота ложного извлечения
- Задержка извлечения

Критерий успеха: 70% восстановление паттерна при 40% потере входа.

#### B. Автоассоциативная реконструкция (прокси CA3)

- Агрегация сходства по top-k
- Реконструкция взвешенным объединением

Метрики:

- Оценка верности реконструкции
- Индекс усиления шума

#### C. Сигнал новизны (прокси CA1)

```python
novelty = 1 - max_similarity(current, recent_N)
```

Проверить:

- Корреляцию новизны с ошибкой предсказания награды
- Влияние новизны на частоту исследования

#### D. Временное контекстное кодирование

Ввести:

- скользящий хеш состояния
- вложение снимка драйвов
- кодирование временного интервала

Метрики:

- Различение извлечения по контексту
- Частота ложных столкновений контекста

### Критерии выхода из фазы 1

- Извлечение не деградирует при росте памяти
- Новизна коррелирует с ошибкой предсказания награды
- Нет экспоненциального роста времени поиска

> **Ожидаемый результат:** гиппокамп 8/10 по биологичности.

## Фаза 2 (месяцы 3–4) — непрерывная эмоциональная регуляция

### 2.1 Цель

Убрать бинарную регуляцию и перейти к тонической модуляции.

### 2.2 Модель

```
alpha = base_alpha * (1 + k * stability_index_centered)
```

Где:

- `stability_index` — экспоненциальное скользящее среднее по недавней волатильности
- `alpha` — аффективная инерция

### 2.3 Эксперименты

#### A. Подавление осцилляций

Метрики:

- Снижение дисперсии аффективного состояния
- Частота перерегулирования

#### B. Скорость адаптации

Метрики:

- Время до стабильности после шокового входа
- Пластичность при низкой стабильности

### 2.4 Убрать разогрев в 500 шагов

Заменить на окно экспоненциального скользящего среднего длиной 30–50.

Тест: устойчивость короткой сессии (менее 100 шагов).

### Критерии выхода из фазы 2

- Снижение амплитуды осцилляций не менее чем на 25%
- Нет коллапса гистерезиса
- Нет поведения мёртвой зоны

## Фаза 3 (месяцы 5–6) — слой конфликта и арбитража (подобный ACC)

### 3.1 Цель

Заменить символического критика на конфликтную динамику.

### 3.2 Конфликтный сигнал

Варианты:

```python
entropy(strategy_distribution)
```

или

```python
conflict = -variance(logits)
```

### 3.3 Правила арбитража

Если `conflict` возрастает:

- температура снижается
- глубина извлечения возрастает
- вес исследования возрастает
- чувствительность к новизне возрастает

### 3.4 Эксперименты

#### A. Тест неоднозначного контекста

- Подать близкие по ценности альтернативы
- Измерить стабильность выбора

Метрики: частота переключений, задержка решения, калибровка уверенности.

#### B. Подавление избыточной уверенности

Если энтропия низкая, а новизна высокая, корректируется ли стратегия?

### Критерии выхода из фазы 3

- Снижение преждевременной сходимости
- Нет патологической нерешительности
- Конфликт стабилизирует поведение

## Фаза 4 (месяц 7) — дофаминовый слой обучения временной разности

### 4.1 Введение функции ценности

```python
delta = r + gamma * V(s') - V(s)
```

Обновление:

- Драйвов
- Логитов стратегии
- Частоты исследования

### 4.2 Интеграция актёра и критика

```
Actor  = strategy logits
Critic = V(s)
```

### 4.3 Эксперименты

#### A. Задача с отложенной наградой

- Награда через N шагов
- Проверить назначение кредита

Метрики: скорость обучения, частота максимизации награды.

#### B. Устойчивость при нестационарности

- Изменение структуры награды
- Проверить адаптивность

### Критерии выхода из фазы 4

- Улучшение долгосрочной отдачи не менее чем на 20%
- Нет неустойчивых осцилляций
- Нет расхождения ценности

## Фаза 5 (месяцы 8–9) — интеграция внешнего мира и консолидация

### 5.1 Сенсорный шлюз

Внешние данные переходят во вложения, затем в гиппокамп. Прямого усвоения по правилам нет.

### 5.2 Конвейер консолидации

- Частые паттерны переходят в кору
- Редкие события удерживаются как эпизоды
- Стробирование новизной задаёт вероятность консолидации

### 5.3 Самоигра и имитация

Запуск:

- Параллельной имитации сценариев
- Контрфактической проверки
- Стресс-теста политики исследования

### 5.4 Метрики

- Оценка обобщения
- Индекс катастрофического забывания
- Эффективность роста памяти

## Итоговая архитектура (целевая)

```
Сенсорный вход
    ↓
Гиппокамп (нечёткий + новизна)
    ↓
Кора (логиты стратегии)
    ↓
Модуляция драйвами
    ↓
Конфликт / арбитраж
    ↓
Действие
    ↓
Среда
    ↓
Награда
    ↓
Ошибка временной разности
    ↓
Обновление памяти и стратегии
```

## Стратегическая цель к концу программы

Не просто механизм решений, а когнитивная архитектура, которая является:

- частично саморегулирующейся
- биологически правдоподобной
- распределённой
- устойчиво обучающейся
- автономной
