## Что это такое?

**Автоматическая тренировка** — это функция, которая позволяет системе NOWA самостоятельно обучаться на наборе данных без необходимости давать оценки вручную.

## Почему это нужно?

### Раньше (вручную):
```
1. Загружу датасет
2. Говорю "кто ты?" → NOWA отвечает как попало
3. Даю оценку звездочками
4. Говорю "как дела?" → NOWA опять отвечает как попало
5. Даю еще оценку
6. ... (повторяю много раз)
7. Система наконец научилась
```

### Теперь (автоматически):
```
1. Загружу датасет
2. Нажму "Авто-тренировка"
3. Вижу как accuracy растет с каждым эпохом
4. За секунды система уже тренирована!
```

## Как использовать в интерфейсе

### Шаг 1: Загрузить набор данных
```
Нажмите кнопку "Загрузить датасет"
  ↓
Выберите способ:
  • Из папки datasets (рекомендуется)
  • Выбрать конкретный файл
  • Выбрать папку вручную
  ↓
Нажмите "Загрузить"
```

**Результат:** вы увидите в чате: «Загружено X опытов из папки datasets».

### Шаг 2: Открыть автоматическую тренировку
```
Нажмите кнопку "Авто-тренировка" (красная кнопка)
  ↓
Откроется новое окно
```

### Шаг 3: Установить параметры

**Количество эпох:**
- Мало (3–5): быстро, но обучение не очень хорошее
- Среднее (5–10): оптимально для малых наборов данных
- Много (10–20): хорошо для больших наборов данных

**Коэффициент обучения:**
- 0.1: медленное, но стабильное обучение
- 0.5: рекомендуется (баланс)
- 1.0: быстрое обучение (может быть нестабильно)

### Шаг 4: Начать тренировку

```
Нажмите зеленую кнопку "▶️ Начать тренировку"
  ↓
Система автоматически:
  1. Берет каждый опыт из датасета
  2. Показывает селектору контекст
  3. Смотрит какое действие выбрал селектор
  4. Сравнивает с правильным из датасета
  5. Даёт награду если правильно, штраф если неправильно
  6. Обновляет веса действий
  ↓
Повторяет это для каждого эпоха
```

### Шаг 5: Смотреть результаты

```
📈 ТОЧНОСТЬ ДО ТРЕНИРОВКИ: 33% (или любой процент)
📈 ТОЧНОСТЬ ПОСЛЕ ТРЕНИРОВКИ: 100% (обычно выше)
✅ Улучшение: +67%

ИСТОРИЯ ПО ЭПОХАМ:
Эпох 1: Accuracy = 33% (1/3)
Эпох 2: Accuracy = 67% (2/3)
Эпох 3: Accuracy = 100% (3/3)
...
```

## Что означают результаты?

### Точность
```
Accuracy = (правильные ответы) / (всего ответов)

Пример:
- Датасет имеет 3 опыта:
  1. "кто ты?" → ответить_кто_я
  2. "как дела?" → сказать_привет
  3. "помоги" → отказаться

ДО тренировки:
- Селектор угадал 1/3 → Accuracy = 33%

ПОСЛЕ тренировки:
- Селектор угадал 3/3 → Accuracy = 100%
```

### История по эпохам
```
Эпох 1: 33% - Только 1 опыт угадан правильно
Эпох 2: 67% - 2 опыта угаданы правильно
Эпох 3: 100% - Все 3 опыта угаданы правильно

Видно что система учится!
```

## Параметры: какие выбрать?

### Для набора данных с 3–5 опытами:
```
Эпохи: 5
Learning rate: 0.5
```

### Для набора данных с 10 и более опытами:
```
Эпохи: 10
Learning rate: 0.5
```

### Для быстрого результата:
```
Эпохи: 3
Learning rate: 0.8
(Может быть менее точным)
```

## Техническое объяснение

### Как работает селектор после загрузки опыта?

```python
# Система содержит два источника информации:
1. Веса действий (базовые)
2. Загруженные опыты

При вводе "кто ты?":
  hippocampus.activate(["user:кто ты?"]) 
    ↓ находит опыт про "ответить_кто_я"
  scores["ответить_кто_я"] += бонус от опыта
    ↓ действие получает дополнительный вес
  Селектор выбирает действие с максимальным score
```

### Как работает тренировка?

```python
for each experience in dataset:
    # Что содержит experience:
    # context: ["user:кто ты"]
    # action: "ответить_кто_я"
    # reward: 1.0
    
    # Что делает тренер:
    chosen = selector.choose(activated_experiences, patterns)
    # chosen = "ответить_кто_я" (если повезло!)
    
    if chosen == experience.action:
        reward = 1.0  # Правильно!
    else:
        reward = -1.0  # Неправильно!
    
    # Обновляем вес
    selector.weights[chosen] += 0.1 * reward
    # "ответить_кто_я": 0.5 → 0.6 (увеличили)
    # или
    # "отказаться": 0.3 → 0.2 (уменьшили)
```

## Частые вопросы

### Вопрос: почему точность не 100%?
**Ответ:** может быть несколько причин:
1. Коэффициент обучения слишком низкий — увеличьте до 0.8
2. Эпох слишком мало — увеличьте до 10–20
3. Набор данных противоречивый (одинаковый контекст ведёт к разным действиям)

### Вопрос: можно ли использовать обучение вручную и автоматическую тренировку?
**Ответ:** да. Вы можете:
1. Загрузить набор данных
2. Запустить автоматическую тренировку
3. Потом давать оценки вручную в диалоге
Всё будет работать вместе.

### Вопрос: как узнать, хороший ли результат?
**Ответ:**
- Точность ниже 50% — нужна доработка
- Точность 50–80% — приемлемо
- Точность выше 90% — отлично

### Вопрос: что если нет набора данных?
**Ответ:** вы можете:
1. Давать оценки вручную (система будет учиться медленнее)
2. Создать файл JSON с опытами
3. Сначала обучить вручную, потом автоматическая тренировка улучшит результат
