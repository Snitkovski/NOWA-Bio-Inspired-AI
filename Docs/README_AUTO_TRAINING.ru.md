## Быстрый старт


```bash

```

## Основные функции

### 1. **Загрузка опыта из датасетов**
- Нажмите "Загрузить датасет"
- Выберите JSON файл с опытами
- Система автоматически добавит их в память

### 2. **Автоматическая тренировка** (новое)
- Нажмите "Авто-тренировка"
- Установите параметры (эпохи, learning rate)
- Система самостоятельно обучается на датасете
- Смотрите accuracy до и после

### 3. **Интерактивный диалог**
- Пишите вопросы
- Даёте оценки (звёздочки)
- Система учится на ваших оценках

### 4. **Инспектор состояния**
- Просмотр всех опытов в памяти
- Статистика действий
- Веса селектора

## Как работает автоматическая тренировка?

```
Датасет JSON → Загрузка → Тренировка → Улучшение accuracy
                          ↓
                    Каждый эпох:
                    1. Берем опыт
                    2. Селектор выбирает действие
                    3. Сравниваем с правильным
                    4. Даем награду/штраф
                    5. Обновляем веса

Результат: Система правильно отвечает на более широкий спектр вопросов!
```

## Примеры использования

### Пример 1: Простая тренировка
```python
from trainer import SelectorTrainer
from loader import load_experiences_from_datasets_folder

# Загружаем опыты
experiences = load_experiences_from_datasets_folder()

# Создаем тренер
trainer = SelectorTrainer(selector, hippocampus, cortex)

# Тренируем
history = trainer.train_full(experiences, epochs=5, learning_rate=0.5)

# Получаем результат
accuracy = trainer.get_accuracy(experiences)
print(f"Accuracy: {accuracy:.2%}")
```

### Пример 2: Детальный анализ

## Параметры тренировки

| Параметр | Значение | Описание |
|----------|----------|---------|
| Эпохи | 5-10 | Количество проходов по датасету |
| `learning rate` | 0.1-1.0 | Скорость обучения (выше = быстрее) |
| `batch size` | - | По одному опыту (можно улучшить) |

**Рекомендации:**
- Для малых датасетов: 5-10 эпох, 0.5 learning rate
- Для больших датасетов: 20+ эпох, 0.1 learning rate

## Решение проблем

### Проблема: Accuracy не улучшается
- Убедитесь что датасет загружен
- Попробуйте увеличить learning rate на 0.7-1.0
- Увеличьте количество эпох до 10-20

### Проблема: Система дает только один ответ
- Это нормально до тренировки
- Нажмите "Авто-тренировка" для обучения
- Или давайте разные оценки вручную

### Проблема: Память переполнена
- Сохраните состояние (кнопка "Сохранить")
- Перезапустите приложение
- Загрузите сохранение
