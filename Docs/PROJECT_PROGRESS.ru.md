### 2. Ключевые свойства

**Временные цепочки:**

- Короткие последовательности событий (2–7 шагов) с ретроспективным net_affect
- Формируются только во время консолидации сна
- Нет обучения, нет градиентов, нет планирования

**Протостратегия:**

- Цепочки смещают выбор действия через `ActionSelector`
- Когда других давлений нет, цепочки детерминированно выбирают действие с наилучшим смещением
- Чистая эмерджентность: нет самоописания, нет целей

**Назначение кредита:**

- Ретроспективный net_affect вычисляется из последствий
- Усредняется по цепочкам и использованию
- Нет обратного распространения и оптимизации на градиентах

**Интеграция со сном:**

- Новый шаг обработки в `SleepManager.sleep_cycle()`
- Формирует цепочки длины 2–7 из недавних гиппокампальных опытов
- Обновляет net_affect цепочки по исходам опыта

**Показ в GUI:**

- Панель памяти показывает число цепочек и среднюю стабильность
- В инспекторе есть отдельный раздел цепочек
- Оценки обратной связи, от неудовольствия до сильного одобрения, используются в расчёте net_affect

## Пример использования

### Создать агента и запустить его с цепочками

```python
from agent import Agent
from hippocampus import NOWAHippocampus
from cortex import CortexMemory
from selector import ActionSelector
from sleep import SleepManager

# Initialize
hip = NOWAHippocampus()
cortex = CortexMemory()
sel = ActionSelector(actions=["action_a", "action_b", "action_c"])
sleep_mgr = SleepManager(hip, cortex)
agent = Agent(hip, cortex, sel, sleep_manager=sleep_mgr)

# Waking behavior
for i in range(20):
    context = ["context:scenario_1"] if i < 10 else ["context:scenario_2"]
    reward = 1.0 if i < 10 else -1.0
    action = agent.step(context, reward=reward)

# Sleep consolidation (chains form here!)
stats = agent.sleep(cycles=3)
print(f"Chains formed: {stats['chains_formed']}")

# Check chain statistics
chains = sleep_mgr.chain_memory.statistics()
print(f"Total chains: {chains['total_chains']}")
print(f"Avg stability: {chains['avg_stability']:.2f}")
```

### Наблюдать поведение протостратегии

После сна агент проявляет предпочтение ранее подкреплённых последовательностей действий без явного планирования:

```python
# Recently rewarded: action_a after context:scenario_1
# Chain forms: ("context:scenario_1", "action:action_a") with net_affect +1.0

# Next time in same context:
context = ["context:scenario_1"]
action = agent.step(context)  # More likely to be "action_a" (proto-strategy)
```
