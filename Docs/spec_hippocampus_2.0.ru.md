## 1. Цели проекта

- Убрать точное сопоставление сигнатуры
- Реализовать нечёткое вспоминание
- Добавить автоассоциативную реконструкцию в духе CA3
- Реализовать обнаружение новизны в духе CA1
- Ввести контекстно-временное кодирование
- Сохранить вычислительную устойчивость

---

## 2. Концептуальная модель

Гиппокамп 2.0 хранит не события, а распределённые сигнатуры состояния.

Сигнатура — это:

```python
signature = {
    "features": set[str],
    "drive_state": vector,
    "context_hash": int,
    "timestamp": int
}
```

## 5. Завершение паттерна в духе CA3

### 5.1 Функция сходства

Основная метрика (сходство Жаккара):

```
similarity(A, B) = |A ∩ B| / |A ∪ B|
```

### 5.2 Алгоритм вспоминания

```python
def recall(current_signature):
    sims = []
    for stored in memory:
        sims.append(similarity(current, stored))

    top_k = select_k_highest(sims)
    return reconstruct(top_k)
```

### 5.3 Реконструкция

```python
def reconstruct(top_k):
    weighted_union = union(features weighted by similarity)
    return weighted_union
```

Вес:

```
w_i = similarity_i / sum(similarity_k)
```

Это аппроксимация автоассоциативного вспоминания.

## 6. Обнаружение новизны в духе CA1

Новизна определяется как:

```
novelty = 1 - max_similarity(current, recent_N)
```

где `recent_N` — последние N эпизодов (окно экспоненциального скользящего среднего).

### 6.1 Интерпретация

| Новизна   | Значение          |
|-----------|---------------|
| < 0.2     | знакомое          |
| 0.2–0.6   | частичное совпадение |
| > 0.6     | новое             |
| > 0.85    | высокая новизна   |

### 6.2 Эффекты ниже по потоку

Новизна используется для:

- повышения драйва исследования
- повышения вероятности консолидации
- повышения скорости обучения
- повышения чувствительности к конфликту

## 7. Временное контекстное кодирование

Добавляется `context_vector`:

```python
context_vector = [
    time_bucket,
    rolling_state_hash,
    discretized_drive_state
]
```

### 7.1 Временные корзины

```python
time_bucket = t % cycle_length
```

Моделирует циркадное и ритмическое кодирование.

### 7.2 Скользящий хеш

```python
rolling_hash = hash(last_k_events)
```

Создаёт контекстную зависимость.

---

## 8. Гейт консолидации

Вероятность консолидации:

```
P(consolidate) = f(novelty, repetition_count, reward_signal)
```

Пример:

```
P = novelty * reward_weight + repetition_factor
```

---

## 9. Затухание памяти

Активационный вес:

```python
activation_weight *= (1 - decay_rate)
```

Удаление:

```python
if activation_weight < threshold:
    delete(signature)
```

## 10. Вычислительные ограничения

- Сложность вспоминания: O(N)
- Возможна оптимизация через инвертированный индекс
- `max_capacity` ограничен
- затухание предотвращает экспоненциальный рост

## 12. План экспериментальной проверки

### 12.1 Восстановление при частичном входе

- Удалить 30–50% признаков
- Проверить восстановление

Цель: 70% верности реконструкции.

### 12.2 Новизна и ошибка предсказания награды

Проверить корреляцию:

```
corr(novelty, TD_error)
```

Ожидается положительная корреляция.

### 12.3 Устойчивость к шуму

- Добавить случайные возмущения признаков
- Проверить долю ложного вспоминания

---

## 13. Режимы отказа

| Отказ                    | Причина                  | Смягчение                    |
|--------------------------|--------------------------|------------------------------|
| Избыточное вспоминание   | низкий порог             | динамический порог           |
| Коллапс памяти           | высокое перекрывание     | более сильное разрежение     |
| Взрыв вспоминания        | большое N                | настройка затухания          |
| Новизна всегда высока    | плохое кодирование признаков | нормализация признаков   |
