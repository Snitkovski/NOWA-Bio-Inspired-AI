## О проекте

Это завершённая реализация системы аффективных регуляторов для NOWA (когнитивная система, разрабатываемая на основе исследований в области искусственного интеллекта и человеческого поведения).

**Главная особенность**: пользователи теперь видят, как «чувствует» агент, благодаря визуализации аффективного состояния в интерфейсе в реальном времени.

---

## Основные возможности

### Визуализация аффективного состояния
```
┌─────────────────────────────┐
│  АФФЕКТИВНОЕ СОСТОЯНИЕ      │
├─────────────────────────────┤
│ Валентность   [████░░] 0.24 │  Настроение
│ Возбуждение   [██░░░░] 0.60 │  Энергия
│ Угроза        [████░░] 0.36 │  Стресс
│ Любопытство   [██░░░░] 0.23 │  Интерес
│ Готовность    0.50           │  Обучаемость
└─────────────────────────────┘
```

### Четыре цветных индикатора
- **Валентность** (красный к зелёному): −1.0 до +1.0 — уровень удовлетворённости
- **Возбуждение** (синий к оранжевому): 0.0 до 2.0 — уровень активации
- **Угроза** (зелёный к красному): 0.0 до 1.0 — уровень стресса
- **Любопытство** (серый к фиолетовому): 0.0 до 1.0 — стремление к исследованию

### Операционная интроспекция
- Показывает **ограничивающие факторы** (что мешает)
- Показывает **поддерживающие факторы** (что помогает)
- Анализирует **паттерны регуляции** (тренды)
- Без субъективной лексики («мне кажется», «я чувствую»)

## Быстрый старт (2 минуты)

### 1. Запустить интерфейс
```bash
cd e:\git\NOWA-Cognitive
python src/gui.py
```

### 2. Использовать
```
1. Напишите сообщение и нажмите Enter
2. Смотрите, как обновляются индикаторы
3. Оцените ответ (−2 до +2) и смотрите, как меняется валентность
4. Откройте «Аффективное состояние» для анализа
```

### 3. Интерпретация
- Зелёная валентность означает положительное состояние
- Красная угроза означает, что система в стрессе
- Фиолетовое любопытство означает, что система интересуется
- Оранжевое возбуждение означает, что система активна

### Новый вопрос
```

    ↓
Любопытство: 0.00 → +0.45
Возбуждение: 0.00 → +0.80
→ Агент исследует новую тему
```

```
Обнаружено противоречие в данных
```
