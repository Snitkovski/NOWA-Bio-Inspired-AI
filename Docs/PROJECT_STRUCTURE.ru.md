## Процесс использования

```
1. ПОЛЬЗОВАТЕЛЬ ПИШЕТ СООБЩЕНИЕ
   │
   ↓
2. АГЕНТ ОБРАБАТЫВАЕТ
   ├── Генерирует ответ
   ├── Вычисляет сигналы (reward/novelty/conflict)
   └── Обновляет affect_state
   │
   ↓
3. ИНТЕРФЕЙС ОБНОВЛЯЕТСЯ
   ├── Красит индикаторы
   ├── Обновляет значения
   ├── Показывает статус готовности
   └── Обновляет инспектор
   │
   ↓
4. ПОЛЬЗОВАТЕЛЬ ВИДИТ РЕЗУЛЬТАТ
   ├── Цвета меняются в реальном времени
   ├── Числа обновляются
   ├── Анализ показывает факторы
   └── Может оценить ответ
   │
   ↓
5. ПОЛЬЗОВАТЕЛЬ ОЦЕНИВАЕТ (-2 до +2)
   │
   ↓
6. ВАЛЕНТНОСТЬ ОБНОВЛЯЕТСЯ
   ├── Отражает оценку
   ├── Готовность может измениться
   └── Процесс повторяется
```

## Если что-то не работает

```
1. Ошибка импорта?
   → Проверьте, что src/ в пути Python
   → pytest использует conftest.py автоматически

2. Интерфейс не запускается?
   → Проверьте, что установлен tkinter
   → Запустите из корневой папки проекта

3. Тесты не проходят?
   → Удалите .pytest_cache/
   → Переустановите пакеты: pip install -r requirements.txt

4. Индикаторы не обновляются?
   → Проверьте консоль на ошибки
   → Убедитесь, что нажали «Отправить»
```

## Ключевые концепции

### AffectiveState (affect.py)
- 4 параметра: valence, arousal, threat, curiosity
- Автоматическое управление границами
- Естественное затухание
- Методы обновления от различных стимулов

### SelfModel (self_model.py)
- Операционная интроспекция
- Без антропоморфизма
- Анализ ограничивающих и поддерживающих факторов
- Расчёт готовности к обучению

### Визуализация интерфейса
- Индикаторы на основе холста
- Цветовое кодирование
- Обновления в реальном времени
- Инспектор для анализа
