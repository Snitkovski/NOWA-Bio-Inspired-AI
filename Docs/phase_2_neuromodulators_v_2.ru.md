## 0. Назначение фазы

Фаза 2 вводит **биологически мотивированную систему нейромодуляторов** как *глобальные регуляторы*:

- скорости обучения
- горизонта времени
- устойчивости и пластичности
- реакции на награду, неопределённость и конфликт

Нейромодуляторы **не**:
- принимают решения
- выбирают действия
- заменяют аффект, намерение и селектор

Они **модулируют**, но не управляют напрямую.

---

## 1. Принципиальная позиция в архитектуре

```
[ Environment ]
      ↓
[ Signals: reward / novelty / conflict ]
      ↓
[ Neuromodulators ]  ← медленные, глобальные
      ↓
[ Affect / Learning / Consolidation / Prediction ]
      ↓
[ Selector / Action ]
```

Ключевая идея:
> **Нейромедиаторы изменяют правила изменения системы, но не её выбор в моменте.**

---

## 2. Набор нейромедиаторов (обязательный минимум)

### 2.1 Дофамин (DA)
**Функция:** ошибка предсказания награды, подкрепление

- усиливает консолидацию
- повышает вероятность повторения паттернов
- ускоряет обучение

### 2.2 Серотонин (5-HT)
**Функция:** стабильность, временной горизонт

- снижает импульсивность
- увеличивает ценность долгосрочных состояний
- стабилизирует привычки

### 2.3 Норадреналин (NE)
**Функция:** неопределённость, бодрствование

- усиливает реакцию на новизну
- повышает исследовательское поведение
- увеличивает чувствительность к сигналам

### 2.4 Кортизол (CORT)
**Функция:** стресс, угроза

- усиливает забывание слабых следов
- снижает обучение при перегрузке
- повышает избегание

---

## 3. Общие свойства нейромодуляторов

- Диапазон значений: **[0.0 – 1.0]**
- Есть базовая линия (по умолчанию ~0.1)
- Есть временное затухание
- Изменяются **медленно**

Никаких скачков больше 0.3 за один шаг.

---

## 4. Формальные правила обновления

### 4.1 Входные сигналы

- `reward` ∈ [-1.0 ; +1.0]
- `novelty` ∈ [0.0 ; 1.0]
- `conflict` ∈ [0.0 ; 1.0]

---

### 4.2 Дофамин

```python
if reward > 0:
    DA += 0.25 * reward
elif reward < 0:
    DA -= 0.10 * abs(reward)
```

Дополнительно:
- рост DA влечёт рост скорости обучения
- рост DA влечёт рост силы консолидации

---

### 4.3 Серотонин

```python
if reward > 0 and conflict == 0:
    HT += 0.05 * reward

if stable_repetition:
    HT += 0.01
```

Эффекты:
- скорость обучения снижается
- временное дисконтирование снижается (длинный горизонт)

---

### 4.4 Норадреналин

```python
NE += 0.30 * novelty
NE += 0.15 * conflict
```

Эффекты:
- исследование растёт
- порождение временных цепочек растёт

---

### 4.5 Кортизол

```python
if reward < 0:
    CORT += 0.20 * abs(reward)

CORT += 0.25 * conflict
```

Эффекты:
- скорость забывания растёт
- порог консолидации растёт

---

### 4.6 Временное затухание

Каждый шаг:

```python
X = X - (X - baseline) * decay_rate
```

Рекомендация:
- `decay_half_life ≈ 60–120 секунд`

---

## 5. Интеграция в существующую систему

### 5.1 Аффект

- аффект **не управляет** нейромедиаторами
- аффект **использует** их как коэффициенты

Пример:
```python
effective_arousal = arousal * (1 + NE)
```

---

### 5.2 Сон и консолидация

Во сне:
- DA ведёт к усилению кортикальных паттернов
- HT ведёт к стабилизации
- CORT ведёт к удалению слабых следов
- NE ведёт к дополнительному формированию цепочек

---

### 5.3 Селектор

Прямое влияние запрещено.

Допустимо **только косвенно**:
- через `affect_modifier`
- через `prediction_pressure`

---

## 6. Жёсткие ограничения (против злоупотребления)

Нельзя:
- выбирать действие на основе DA
- делать условие «если DA больше порога, то действие»
- хранить предпочтения в нейромодуляторах
- использовать их как эмоции

Можно:
- менять коэффициенты
- влиять на скорость забывания
- менять вес предсказания

### TC-1: Положительное подкрепление
- reward = +1.0
- ожидание: DA растёт, HT растёт (слабо)

### TC-2: Негатив и конфликт
- reward = -0.8, conflict = 0.6
- ожидание: CORT сильно растёт, DA снижается

### TC-3: Новизна
- novelty = 1.0
- ожидание: NE растёт, исследование растёт

### TC-4: Временной спад
- без сигналов 120 секунд
- ожидание: все возвращаются к базовой линии

### TC-5: Сон и высокий DA
- ожидание: усиление кортикальных паттернов

## 10. Архитектурное напоминание

> Нейромедиаторы — это **метауровень регуляции**,
> а не интеллект и не чувства.

Без них невозможны:
- стратегия
- предсказание
- чувства как процессы
