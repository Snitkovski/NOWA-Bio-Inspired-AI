## Назначение фазы

Phase 3.75 вводит **устойчивый аффективный фон** (affective background field), формируемый из долговременных аффективных следов (Phase 3.5), физиологического бодрствования и **прогресса времени жизни агента**.

Фаза:
- не принимает решений
- не выбирает действия
- не генерирует эмоции
- не управляет мотивацией

Её задача — создать **инерционное, медленно меняющееся фоновое состояние**, на котором в будущем (Phase 4+) смогут возникать чувства и мотивационные конструкции.

---

## Ключевая идея

> Lifetime — это **не знание о смерти и не экзистенциальный фактор**,
> а **мета-параметр динамики аффективного поля**.

Он влияет **только на то, как быстро и устойчиво меняется фон**,
а не на то, *что* агент чувствует или делает.

---

## Входы

### Обязательные

- **Affective Traces** (из Phase 3.5)
  - anxiety, tension, satisfaction, interest, …
  - интенсивность ∈ [0..1]

- **Wakefulness Level**
  - физиологическое бодрствование ∈ [0..1]
  - влияет на шум и стабильность, но не на силу фона

- **Lifetime Progress** ∈ [0..1]

```text
lifetime_progress = clamp(
    lived_steps / expected_lifetime_steps,
    0.0,
    1.0
)
```

Где:
- `lived_steps` — сколько шагов агент уже существует
- `expected_lifetime_steps` — архитектурная константа масштаба времени

Lifetime не является:
- сигналом
- стимулом
- осознаваемым знанием

---

## Выходы

- **Affective Background Field**
  - набор фоновых компонент (не эмоций)
  - медленно меняющиеся значения ∈ [0..1]

Пример:
```json
{
  "background_anxiety": 0.32,
  "background_tension": 0.41,
  "background_satisfaction": 0.18,
  "background_interest": 0.27
}
```

---

## Архитектурные компоненты

### 1. Инерция фона

Определяет, насколько быстро фон реагирует на новые следы.

```text
inertia = base_inertia * (1 + lifetime_progress * k_life)
```

- молодой агент → низкая инерция
- «поживший» агент → высокая инерция

---

### 2. Модуляция затухания

Lifetime снижает скорость затухания фона:

```text
background_decay_rate = base_decay * (1 - lifetime_progress * k_decay)
```

Интерпретация:
- ранние этапы → фон легко исчезает
- поздние этапы → фон держится долго

---

### 3. Резкость конкуренции

Lifetime усиливает конкуренцию между фоновыми компонентами:

```text
competition_sharpness = base_sharpness * (1 + lifetime_progress * k_comp)
```

Эффект:
- молодой агент → много слабых фоновых влияний
- зрелый агент → 1–2 доминирующих

---

### 4. Взаимодействие с бодрствованием

Wakefulness:
- не усиливает фон
- не ослабляет фон
- влияет только на **шум обновления**

```text
update_noise ∝ (1 - wakefulness)
```

Усталость = нестабильность, а не сила.

---

## Строгие ограничения

Модуляция Lifetime **не может**:

- генерировать affect signals
- увеличивать threat или valence
- влиять на selector / basal ganglia
- передаваться в neuromodulators
- интерпретироваться как знание о возрасте

---

## Тест-кейсы

### Тест 1 — Рост инерции с временем жизни

```
Given identical affective traces
And lifetime_progress = 0.1 vs 0.9
Then:
- older agent background changes slower
- steady‑state values identical
```

Дано: одинаковые аффективные следы.
И `lifetime_progress` = 0.1 против 0.9.
Тогда:
- фон более старого агента меняется медленнее
- значения установившегося состояния идентичны

---

### Тест 2 — Отсутствие инъекции аффекта от времени жизни

```
Given increasing lifetime_progress
Then:
- no direct increase in anxiety, threat, valence
- only temporal dynamics change
```

Дано: растущий `lifetime_progress`.
Тогда:
- нет прямого роста anxiety, threat, valence
- меняется только временная динамика

---

### Тест 3 — Независимость от бодрствования

```
Given same lifetime_progress
And wakefulness = 1.0 vs 0.2
Then:
- mean background equal
- variance / noise differs
```

Дано: одинаковый `lifetime_progress`.
И wakefulness = 1.0 против 0.2.
Тогда:
- средний фон равен
- дисперсия и шум различаются

---

### Тест 4 — Резкость конкуренции

```
Given multiple weak traces
Then:
- young agent keeps several backgrounds
- old agent converges to fewer dominant ones
```

Дано: несколько слабых следов.
Тогда:
- молодой агент сохраняет несколько фонов
- старый агент сходится к меньшему числу доминирующих

---

## Анти-паттерны

Запрещено:
- использовать Lifetime как мотивацию
- отображать Lifetime на страх или печаль
- открывать Lifetime когниции
- позволять Lifetime влиять на выбор действия

---

## Позиция автора (архитектурные заметки)

Эта фаза — последний уровень **до появления субъективных чувств**.

Она описывает:
- накопленную историю существования
- телесную и временную инерцию
- устойчивость внутреннего мира

Без символов.
Без эмоций.
Без решений.

---

## Готовность

Phase 3.75 считается завершённой, если:
- lifetime влияет только на динамику
- нет утечек в принятие решений
- поведение остаётся идентичным при равных входах
