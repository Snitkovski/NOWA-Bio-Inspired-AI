# Фаза 3: базальные ганглии / пропускание действий (BG-AG)

English version: [phase_3_basal_ganglia_action_gating_specification.en.md](phase_3_basal_ganglia_action_gating_specification.en.md)

**Статус (27 сентября 2026 г.).** Документ ядра. Актуальное научное изложение комплекса на русском и английском языках приведено в [SCIENTIFIC_DESCRIPTION.ru.md](SCIENTIFIC_DESCRIPTION.ru.md). Текст ниже сохраняет формулировки исходной редакции: это нормативный контракт модуля либо лабораторная запись.

## Цель фазы

Создать **биологически правдоподобный механизм выбора действий**, в котором:

- решения не принимаются единственным модулем;
- конкурируют альтернативы (Go / NoGo);
- нейромодуляторы **модулируют** вероятность выбора, а не диктуют его;
- PFC / Prediction Layer остаются **совещательными**;
- привычки (habits) могут как усиливаться, так и подавляться.

Фаза 3 вводит **базальные ганглии** как центральный *шлюз* принятия действия.

---

## Архитектурные принципы

1. **Decision ≠ Generation**
   Базальные ганглии выбирают *намерение действия*, а не текст или реализацию.

2. **Competition, not scoring**
   Действия соревнуются через каналы Go / NoGo.

3. **Neuromodulators modulate**
   Дофамин, серотонин, норадреналин и кортизол меняют *веса каналов*, но не выбирают действие.

4. **PFC = advisory**
   Prediction / Plan C / PFC может только:
   - усиливать
   - ослаблять
   - добавлять шум

5. **Sleep-dependent plasticity**
   Обучение каналов происходит **только во сне**.

## Новые компоненты

### 1. ActionChannel

Минимальная единица выбора действия.

**Состояние:**

```python
ActionChannel:
  action_id: str
  go_weight: float        # [0.0 .. 1.0]
  nogo_weight: float      # [0.0 .. 1.0]
  habit_strength: float   # [0.0 .. 1.0]
```

**Инварианты:**

- go_weight и nogo_weight не обязаны суммироваться к 1
- канал не знает о других каналах

---

### 2. BasalGangliaGate

Центральный модуль выбора.

**Входы:**

- кандидаты действий (ActionChannels)
- affective pressure
- neuromodulators
- wakefulness
- PFC advisory pressures

**Выход:**

- выбранное action_id

**Интерфейс:**

```python
class BasalGangliaGate:
    def choose(self,
               channels: List[ActionChannel],
               affect: AffectiveState,
               neuromodulators: NeuromodulatorState,
               wakefulness: WakefulnessState,
               pfc_pressure: Dict[str, float] = None
    ) -> str
```

---

## Механика Go / NoGo

### Базовые формулы

Для каждого канала `i`:

```text
Go_i   = go_weight_i   * DA_modifier * affect_modifier
NoGo_i = nogo_weight_i * CORT_modifier

Net_i = Go_i - NoGo_i
```

Где:

- `DA_modifier = f(dopamine)`
- `CORT_modifier = f(cortisol)`
- `affect_modifier` — из AffectiveState

### Влияние нейромодуляторов

| Модулятор | Эффект |
|---------|-------|
| Dopamine | усиливает Go, снижает NoGo |
| Serotonin | повышает стабильность, снижает флуктуации |
| Norepinephrine | повышает шум и исследование |
| Cortisol | усиливает NoGo, повышает порог выбора |

---

## Интеграция PFC / Prediction Layer

PFC **не может**:

- напрямую выбрать действие
- отменить базальные ганглии

PFC **может**:

```text
Net_i += pfc_pressure_i * wakefulness_modifier
```

Где:

- `wakefulness_modifier` уменьшается при усталости
- высокий шум делает давление менее точным

---

## Стохастический выбор

После вычисления `Net_i`:

1. Отсекаются действия ниже порога:

```text
Net_i < threshold → reject
```

2. Из оставшихся:

- softmax с температурой, зависящей от NE

```text
P(action_i) = softmax(Net_i / temperature)
```

## Обучение (только во сне)

### Пластичность базальных ганглиев во сне

Во время `SleepManager.deep_sleep()`:

#### Положительный исход:

```text
go_weight += DA * learning_rate
nogo_weight -= DA * learning_rate
```

#### Отрицательный исход:

```text
go_weight -= CORT * learning_rate
nogo_weight += CORT * learning_rate
```

#### Укрепление привычки:

```text
habit_strength += repetition * serotonin
```

Все обновления:

- ограничены
- с forgetting_rate из нейромодуляторов

## Отличия от предыдущего Selector

| Старый Selector | Базальные ганглии |
|---------------|---------------|
| линейное давление | конкуренция каналов |
| выбор максимума | стохастический отбор |
| привычки как смещение | привычки как канал |
| нет NoGo | явный NoGo |

---

## Антипаттерны (критично)

- Базальные ганглии принимают решение без аффекта
- PFC перекрывает результат
- Обучение базальных ганглиев в бодрствовании
- Один глобальный скоринг
- Отсутствие шума при высоком NE

## Тест-кейсы

### TC1: смещение дофамина

- DA растёт
- ожидается: чаще выбираются каналы Go

### TC2: торможение кортизолом

- CORT растёт
- ожидается: доминирует NoGo

### TC3: доминирование привычки

- habit_strength = 0.9
- ожидается: устойчивый выбор при нейтральных условиях

### TC4: совещательное давление PFC игнорируется при усталости

- wakefulness > 0.7
- давление PFC высоко
- ожидается: слабое влияние PFC

### TC5: исследование при NE

- NE растёт
- ожидается: рост энтропии выбора

### TC6: обучение во сне

- повтор положительного исхода
- сон
- go_weight растёт

## Критерии успешной реализации

- Базальные ганглии выбирают действия без Selector
- У PFC нет права вето
- Поведение деградирует при усталости
- Сон улучшает стабильность
- Возможны «ошибки», но они статистически объяснимы
