| отображение в интерфейсе | поставлено | статистика цепочек в панели памяти |

### 2. Принципы отсутствия обучения сохранены

- **Нет градиентов** — чистая арифметика над значениями `net_affect`
- **Нет обратного распространения** — ретроспектива, а не итерация
- **Нет целей** — цепочки нейтральны к исходу
- **Нет планирования** — только сопоставление исторических последовательностей
- **Нет оптимизации** — простое усреднение, без весов
- **Нет самоповествования** — цепочки существуют, но не описываются

### 3. Формирование только во сне

Цепочки формируются **исключительно во время консолидации сна:**
- Поведение в бодрствовании: только сохранение опыта
- Циклы сна: цепочки формируются из недавних последовательностей опыта
- Вне сна цепочки не обновляются
- Сохраняется чистое разделение обучения и бодрствования

## Ключевые свойства

### Протостратегия без планирования

Цепочки создают возникающие поведенческие паттерны:
- **Память последовательности:** каждая цепочка хранит последовательность событий фиксированной длины
- **Корреляция с исходом:** связана с ретроспективным `net_affect`
- **Применение смещения:** цепочки смещают выбор действия, не диктуя его
- **Возникновение:** стратегия появляется через сцепление, а не через явную модель

### Отложенная оценка

```
Scenario A: action_a after context_1 → reward +1.0
Scenario B: action_b after context_1 → reward -1.0

After sleep:
  Chain A: ("context_1", "action:action_a") → net_affect +1.0
  Chain B: ("context_1", "action:action_b") → net_affect -1.0

Result: Agent slightly prefers action_a in context_1
WITHOUT being told the rule or learning weights
```

### Контекстное различение

Цепочки различают одинаковые действия в разных контекстах:
- Одно и то же действие в разных контекстах даёт разные цепочки
- Разные действия в одном контексте дают разные исходы
- Различение естественно возникает из сопоставления последовательностей событий

## Пример использования

### Настройка
```python
from agent import Agent
from hippocampus import NOWAHippocampus
from cortex import CortexMemory
from selector import ActionSelector
from sleep import SleepManager

hip = NOWAHippocampus()
cortex = CortexMemory()
selector = ActionSelector(actions=["action_a", "action_b"])
sleep_mgr = SleepManager(hip, cortex)  # ChainMemory auto-created
agent = Agent(hip, cortex, selector, sleep_manager=sleep_mgr)
```

### Тренировка
```python
# Waking phase (no chains yet)
for i in range(50):
    context = ["scenario:test"]
    reward = 1.0 if i < 25 else -1.0
    action = agent.step(context, reward=reward)

# Sleep phase (chains form here!)
stats = agent.sleep(cycles=3)
print(f"Chains formed: {stats['chains_formed']}")

# Continue waking (chains now influence behavior)
action = agent.step(["scenario:test"])  # Proto-strategy bias applied
```
