## Обзор

Графический интерфейс NOWA полностью переработан в соответствии с новой когнитивной архитектурой, в которой **поведение возникает через консолидацию во сне, а не через обучение в бодрствовании**.

## Основные изменения

### Удалено

1. **Прямое обучение во время бодрствования**
   - вызовы `selector.learn()`
   - обновление весов по награде
   - прямое обучение по точности

2. **Диалоги тренировки**
   - кнопка «Тренировка» теперь показывает предупреждение об устаревании
   - кнопка «Авто-тренировка» теперь показывает предупреждение об устаревании
   - использование `SelectorTrainer`

3. **Отображение весов селектора**
   - вкладка «Веса действий»
   - визуализация весов и столбчатые диаграммы
   - параметры скорости обучения

### Добавлено

1. **Диалог консолидации сна**
   - кнопка «Сон» — новый основной механизм обучения
   - настройка циклов консолидации (1–10)
   - просмотр статистики консолидации
   - отслеживание формирования паттернов

2. **Расширенный инспектор**
   - 5 вкладок вместо 4:
     - «Эпизодическая память» (опыты)
     - «Семантическая память» (паттерны)
     - «Выбор действий» (без весов, на основе давления)
     - «Консолидация» — конвейер консолидации сна
     - «Статистика» — общая статистика

3. **Отображение когнитивного состояния**
   - показывает циклы консолидации
   - показывает счётчики подкрепления опыта
   - показывает значения силы паттерна
   - коэффициент консолидации (паттерны / опыты)

### Изменено

1. **Механизм обратной связи**
   - Прежде: прямая оптимизация весов
   - Теперь: сохранение опыта с интенсивностью (0.2–1.0)
   - Показывается сообщение: «Опыт сохранён. Используйте Сон для консолидации.»
   - Интенсивность вычисляется по пятибалльной шкале:
     - очень плохо = 0.2
     - плохо = 0.4
     - нейтрально = 0.6
     - хорошо = 0.8
     - отлично = 1.0

2. **Отображение статистики**
   - Прежде: показывались веса селектора и средние значения
   - Теперь показывается:
     - последнее выполненное действие
     - общее число опытов в гиппокампе
     - общее число паттернов в коре
     - циклы консолидации сна

3. **Отображение памяти**
   - статистика эпизодической памяти (счётчики подкрепления)
   - статистика семантической памяти (сила паттерна)
   - число циклов консолидации

4. **Загрузка опыта**
   - опыты загружаются в гиппокамп (не непосредственно в кору)
   - интенсивность задаётся по данным опыта
   - учитываются счётчики подкрепления

## Рабочий процесс

### 1. БОДРСТВОВАНИЕ: взаимодействие
```
User: "Hello"
  ↓
Agent: Takes action based on current memory
  ↓
User: Rates response (very poor to excellent)
  ↓
System: Stores experience with intensity
```

### 2. СОН: консолидация
```
Click: Sleep button
  ↓
Configure: Number of cycles (1-10)
  ↓
System: Consolidates experiences to patterns
  - Replay similar experiences
  - Cluster related memories
  - Abstract into semantic patterns
  - Forget unstable traces
  ↓
Result: New behavior based on consolidated patterns
```

### 3. СНОВА БОДРСТВОВАНИЕ: поведение меняется
```
User: "Hello"
  ↓
Agent: Action selection now uses:
  - Hippocampal activation (recent + reinforced)
  - Cortical patterns (consolidated memories)
  - Pressure-based choice (NOT weights)
  ↓
Behavior EMERGES from consolidation!
```

## Вкладки инспектора

### 1. Эпизодическая память
Показывает все опыты в гиппокампе:
- сигнатура (хеш контекста)
- события (контекст, действие, следствие)
- интенсивность (0–2)
- счётчик подкрепления (число повторений)
- последнее активационное время

### 2. Семантическая память
Показывает кортикальные паттерны, созданные во время сна:
- сигнатура (абстрагированный паттерн)
- сила (сила консолидации)
- момент создания (когда произошла консолидация)

Паттерны появляются только ПОСЛЕ консолидации сна.

### 3. Выбор действий
Показывает, что селектор имеет:
- словарь весов отсутствует
- метод `learn()` отсутствует
- скорость обучения отсутствует
- порог уверенности 0.7
- выбор основан на давлении, а не на весах

### 4. Консолидация
Показывает конвейер сна:
1. **Воспроизведение:** усиление активных воспоминаний
2. **Кластеризация:** группировка сходных опытов
3. **Консолидация:** абстракция в паттерны
4. **Забывание:** удаление неустойчивых следов

Статистика:
- общее число завершённых циклов сна
- опыты в гиппокампе
- паттерны в коре
- коэффициент консолидации

### 5. Статистика
Сводка состояния агента:
- всего сохранено опытов
- всего сформировано паттернов
- завершено циклов сна
- среднее подкрепление на опыт
- средняя сила паттерна
- последнее выполненное действие

## Проверка основного принципа

**Вопрос:** если селектор заморожен и агент получает новый опыт, изменится ли поведение?

**Ответ:** да, через консолидацию сна:
1. Новые опыты накапливаются в гиппокампе
2. Сон кластеризует и консолидирует их
3. Кортикальные паттерны смещаются
4. Давление выбора меняется (активация гиппокампа и смещение паттерна)
5. Поведение возникает иным

**Отсюда следует:** обучение происходит во СНЕ, а не во время бодрствования.
