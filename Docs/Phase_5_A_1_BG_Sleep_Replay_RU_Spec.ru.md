## Консолидация по TD, управляемая воспроизведением (полная спецификация)

------------------------------------------------------------------------

# 1. Статус фазы

Тип: архитектурное расширение  
Приоритет: высокий  
Зависимости:
- слой ценности (фаза 5.0.1)
- временная система (T1/T2/T3)
- `BasalGangliaLearning` (существующий класс)
- монитор устойчивости (фаза 4.5)

Эта фаза не изменяет:
- слой планирования
- выбор политики во время выполнения
- аффективную динамику напрямую

------------------------------------------------------------------------

# 2. Цель фазы

Реализовать биологически правдоподобную офлайн-консолидацию привычек во
время сна, основанную на:

- ошибке TD
- воспроизведении эпизодов
- ограниченном подкреплении
- строгой защите от самоусиления

------------------------------------------------------------------------

# 3. Архитектурные изменения

В `sleep_cycle()` обязательно добавить:

1. Формирование `replay_sample`
2. Офлайн-обновление TD
3. Подкрепление базальных ганглиев
4. Мягкое затухание
5. Нормализацию
6. Проверку устойчивости

```text
sleep_cycle(): if instability_flag: skip replay

    replay_sample = select_replay()

    for episode in replay_sample:
        td = compute_td_error_offline(...)
        update_value(td)
        update_bg_weights(td)

    apply_decay()
    normalize()
```

------------------------------------------------------------------------

# 4. Отбор воспроизведения

## 4.1 Функция приоритета

```text
priority = w1 * |TD_error_snapshot|
+ w2 * salience
+ w3 * importance
```

Где:
- `TD_error_snapshot` сохранён во время бодрствования
- salience не зависит от текущего аффекта
- importance вычисляется без использования текущего состояния осей

## 4.2 Ограничения

- `replay_budget_per_sleep` ≤ K
- `max_replay_per_episode` ≤ N
- стохастическая взвешенная выборка
- если `variance(ValueLayer)` > порога, воспроизведение запрещено

------------------------------------------------------------------------

# 5. Офлайн-обновление TD

`V(s) ← V(s) + alpha_sleep * TD_error`

Ограничения:

- `alpha_sleep` ≤ 0.25 * `alpha_online`
- `TD_error` обязательно проходит `clip()`
- `|ΔV|` ≤ `delta_value_max_per_sleep`
- суммарное `|ΔV|` за сон ≤ `value_total_cap`

Запрещено:
- использовать текущий аффект как множитель TD
- увеличивать `gamma`

------------------------------------------------------------------------

# 6. Подкрепление базальных ганглиев

`W(s,a) ← W(s,a) + beta_sleep * clipped(TD_error)`

Ограничения:

- `beta_sleep` < `beta_online`
- `|ΔW|` ≤ `delta_weight_max_per_sleep`
- суммарный прирост веса ≤ `weight_total_cap`
- `TD_error` ограничен

------------------------------------------------------------------------

# 7. Мягкое затухание

После воспроизведения:

`W ← W * (1 - decay_rate_sleep)`

Требования:
- `decay_rate_sleep` малый (например 0.01–0.05)
- затухание обязательно в каждый сон

------------------------------------------------------------------------

# 8. Нормализация

Для каждого состояния `s`:

`sum_a |W(s,a)|` ≤ `weight_norm_cap`

Если превышено:

`W(s,a) ← W(s,a) * (weight_norm_cap / current_sum)`

Нормализация обязательна.

------------------------------------------------------------------------

# 9. Защита от неуправляемого роста

Обязательные механизмы:

1. Бюджет воспроизведения ограничен
2. Ограничение TD
3. ΔW ограничен
4. ΔV ограничен
5. Монитор неустойчивости блокирует воспроизведение
6. Аффективное состояние не участвует напрямую
7. Нормализация обязательна

Без любого из этих пунктов фаза считается некорректной.

------------------------------------------------------------------------

# 10. Инварианты системы

После сна:

- все веса конечны
- `ValueLayer` остаётся в диапазоне `[-value_cap, value_cap]`
- нет экспоненциального роста
- нет самоподкрепляющихся петель

------------------------------------------------------------------------

# 11. Тест-кейсы

## 11.1 Усиление полезной привычки

Условие:
- повторяющийся `s`
- `TD_error` > 0

Ожидается:
- рост `W(s,a)`
- рост `V(s)`
- `weight_norm_cap` не превышен

------------------------------------------------------------------------

## 11.2 Ослабление вредной привычки

Условие:
- `TD_error` < 0

Ожидается:
- снижение `W(s,a)`
- нет неуправляемого отрицательного роста

------------------------------------------------------------------------

## 11.3 Защита от неуправляемого роста

Условие:
- `TD_error` высокий
- частое воспроизведение

Ожидается:
- ΔW ограничен
- нормализация срабатывает
- система стабильна

------------------------------------------------------------------------

## 11.4 Блокировка при неустойчивости

Условие:
- `variance(ValueLayer)` > порога

Ожидается:
- воспроизведение не выполняется
- сон завершается без подкрепления

------------------------------------------------------------------------

## 11.5 Тест аффективной изоляции

Условие:
- высокая аффективная активация
- `TD_error` ≈ 0

Ожидается:
- эпизод не получает приоритет
- нет роста веса

------------------------------------------------------------------------

## 11.6 Тест бюджета воспроизведения

Условие:
- `replay_budget` = K

Ожидается:
- обработано не более K эпизодов

------------------------------------------------------------------------

# 12. Критерии завершения фазы

Фаза считается завершённой, если:

- привычки усиливаются через повторение
- негативные паттерны ослабевают
- нет неуправляемой динамики
- `ValueLayer` стабилен
- аффективный контур не влияет напрямую на консолидацию
