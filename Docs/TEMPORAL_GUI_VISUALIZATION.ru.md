## Обзор

В интерфейс NOWA добавлена полная визуализация временных уровней, чтобы показывать четырёхуровневую темпоральную архитектуру (T0/T1/T2/T3) для отладки и для понимания паттернов поведения агента во времени.

## Реализация

### 1. Добавление панели интерфейса (`src/gui.py`)

В правую панель добавлен раздел «Временные уровни»:
- **Расположение**: после отображения аффективного состояния, перед разделом статистики
- **Строки**: 248–285

#### Компоненты отображения

- **T0 (мгновение)**: мгновенное текущее аффективное состояние
  - Показывает: valence, arousal, threat, curiosity (текущие значения)
  - Обновляется на каждом шаге агента

- **T1 (тренд)**: краткосрочный тренд (скользящее окно)
  - Показывает: средние значения по окну из 10 элементов и дельты относительно T0
  - Показывает направление изменения (+/−) по каждому измерению аффекта
  - Индикатор заполнения окна (от 0/10 до 10/10)

- **T2 (baseline)**: консолидированная среднесрочная базовая линия
  - Показывает: устойчивое опорное состояние с медленным дрейфом бодрствования
  - Обновляется во время бодрствования (микроконсолидация) и во время циклов консолидации сна

- **T3 (аттрактор)**: долгосрочные аттракторы (очень медленная эволюция)
  - Показывает: очень устойчивое смещение поведения
  - Обновляется только во время циклов глубокого сна

## Поток данных

### Во время шагов агента (бодрствование)

```text
User Input → Agent.step() → temporal.log(snapshot) → T0 updated
                         → T1 accumulates (deque, max 10)
                         → T2 drifts when T1 window is full
                         → GUI.process_input() → update_temporal_display()
```

### Во время консолидации сна

```text
Agent.sleep(cycles=N) → temporal.sleep() → consolidate T1→T2, T2→T3
                     → update affect aggregates
                     → GUI.update_temporal_display()
```

## Испытания

### Проверочные тесты

1. У агента есть атрибут `temporal` (экземпляр `TemporalLevels`)
2. T0 содержит все измерения аффекта (valence, arousal, threat, curiosity)
3. T1 корректно накапливает окно из 10 элементов
4. T2 дрейфует во время бодрствования и обновляется после консолидации сна
5. Аттракторы T3 отслеживают долгосрочные паттерны
6. Отображение обрабатывает отсутствие данных без отказа
7. Все 167 модульных тестов по-прежнему проходят (регрессий нет)

## Применение при отладке

### Понимание поведения агента

- **Значения T0**: что агент переживает в данный момент
- **Дельты T1**: становится ли агент тревожнее, спокойнее или любопытнее
- **Базовая линия T2**: «обычное» эмоциональное состояние агента после обучения
- **Аттракторы T3**: эмоциональный паттерн, к которому агент тяготеет в долгом времени

### Сценарии отладки

1. **Агент застрял в негативном состоянии**: проверить аттракторы T3 — смещены ли они в негатив
2. **Поведение меняется беспорядочно**: проверить окно T1; высокая волатильность указывает на неустойчивость
3. **Обучение не действует**: проверить дрейф T2 во время бодрствования и обновление T2/T3 после сна (циклы консолидации)
4. **Неожиданная личность**: смотреть на T3; долгосрочные аттракторы отражают выученную личность
