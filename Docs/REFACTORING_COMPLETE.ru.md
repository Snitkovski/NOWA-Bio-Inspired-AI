### 2. **Селектор — необучаемый**
- Удалены все обучаемые веса (атрибут `.weights` удалён)
- Метод `.learn()` удалён целиком
- Реализован механизм решения по уверенности
- Детерминированный или стохастический выбор зависит от порога уверенности

**Как это работает:**
- Давление считается по опытам гиппокампа
- Добавляется смещение корковых паттернов
- Уверенность = max_pressure / total_pressure
- Если уверенность выше порога, выбор детерминированный
- Если уверенность не выше порога, выбор стохастический (взвешенный по вероятности)

**Изменённые файлы:**

### 4. **Сон — единственный механизм обучения**
- Консолидация во сне — единственный способ, которым происходит обучение
- Нет обучения во время бодрствования
- Кластеризация сходных опытов
- Абстракция в корковые паттерны
- Забывание неустойчивых следов

**Процесс цикла сна:**
1. **Повтор** — усиление опытов
2. **Кластер** — группировка сходных опытов
3. **Консолидация** — абстракция в корковые паттерны
4. **Забывание** — удаление неустойчивых опытов и опытов с низкой активацией

## Ключевое архитектурное наблюдение

Рефакторинг реализует принцип **возникновения поведения**:

1. **Нет прямого обучения:** у селектора нет весов, скорости обучения и оптимизации
2. **Сохранение опыта:** все опыты иммутабельны после создания
3. **Консолидация во сне:** единственный механизм обобщения паттернов
4. **Выбор по уверенности:** детерминированный при уверенности, исследовательский при неопределённости
5. **Естественное забывание:** опыты с низкой активацией и слабым подкреплением угасают

**Итог:** поведение агента не оптимизируется к цели, а **возникает** естественным образом из:
- активации недавнего опыта (гиппокамп)
- консолидированных поведенческих паттернов (кора)
- разрешения конфликта через уверенность

## Проверка основного принципа

**Вопрос:** если селектор заморожен и агент получает новый опыт, изменится ли поведение?

**Ответ:** да. Поведение меняется так:
1. Новые опыты сохраняются в гиппокампе
2. Консолидация во сне абстрагирует паттерны
3. Корковые паттерны влияют на вход селектора
4. Порог уверенности определяет стохастичность

Это NOWA, а не машинное обучение. Агент не оптимизируется: он адаптируется.
