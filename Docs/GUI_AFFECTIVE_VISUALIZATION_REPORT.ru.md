## 1. Обзор

Графический интерфейс дополнен визуализацией аффективного состояния в реальном времени. Система показывает все четыре основных аффективных параметра цветовыми индикаторами, так что конечный пользователь наблюдает и понимает изменения операционного состояния агента в реальном времени.

## 2. Сводка реализации

### 2.1 Изменения GUI (`src/gui.py`)

#### Новые импорты
```python
from affect import AffectiveState
from self_model import SelfModel
```

#### Расширение окна
- **Прежний размер**: 900x700
- **Текущий размер**: 1200x750 (расширено под аффективные индикаторы)

#### Панель отображения аффективного состояния

Новый раздел `affect_frame` на правой панели показывает:

**1. Индикатор валентности**
- Диапазон: −1.0 (сильно отрицательная) до +1.0 (сильно положительная)
- Цветовая кодировка: от красного к зелёному
- Метка: текущее значение с двумя знаками после запятой
- Интерпретация: текущее удовлетворение или неудовлетворение агента

**2. Индикатор возбуждения**
- Диапазон: 0.0 (спокойствие) до 2.0 (сильная активация)
- Цветовая кодировка: от синего к оранжевому
- Метка: текущее значение с индикатором интенсивности
- Интерпретация: уровень активации или энергии агента

**3. Индикатор угрозы**
- Диапазон: 0.0 (безопасно) до 1.0 (критическая угроза)
- Цветовая кодировка: от зелёного к красному
- Метка: текущее значение с уровнем предупреждения
- Интерпретация: воспринимаемая опасность или неустойчивость

**4. Индикатор любопытства**
- Диапазон: 0.0 (безразличие) до 1.0 (сильное любопытство)
- Цветовая кодировка: от серого к фиолетовому
- Метка: текущее значение с готовностью к исследованию
- Интерпретация: стремление агента исследовать или учиться

**5. Метка готовности**
- Вычисляется методом `adaptation_readiness()`
- Показывает: числовое значение (0.0–1.0) и статус (готов / обработка / ограничено)

### 2.2 Методы визуализации

#### `_update_bar(canvas, value, min_val, max_val, low_color, high_color)`
Создаёт цветовую полосу на Canvas:
- Динамически вычисляет положение и цвет полосы по значению
- Поддерживает любой диапазон значений и пару цветов
- Обновляется в реальном времени на шагах агента

#### `update_affect_display()`
Обновляет все аффективные индикаторы:
- Вызывается после каждого `agent.step()`
- Обновляет полосы Canvas текущими значениями
- Обновляет текстовые метки точными измерениями
- Интегрируется с SelfModel для полного анализа

### 2.3 Интеграция в реальном времени

#### Интеграция шага агента
```python
def process_input(self):
    # ... agent processing ...
    self.update_affect_display()  # Updates after each step
```

#### Интеграция системы обратной связи
```python
def submit_feedback(self):
    # ... existing code ...
    reward_signal = feedback_rating / 2.0  # -1.0 to 1.0
    self.agent.affect_state.update_from_reward(reward_signal)
    self.update_affect_display()  # Visual update after feedback
```

### 2.4 Расширение вкладки инспектора

- Анализ регуляторных паттернов

- Поддерживающие факторы (что поддерживает поведение)

## 3. Технические подробности

### 3.1 Схема цветовой кодировки

| Параметр | Минимум | Максимум | Диапазон цвета | Смысл |
|-----------|-----------|-----------|-------------|---------|
| **Валентность** | −1.0 | +1.0 | от красного к зелёному | от отрицательного настроения к положительному |
| **Возбуждение** | 0.0 | 2.0 | от синего к оранжевому | от спокойствия к гиперактивации |
| **Угроза** | 0.0 | 1.0 | от зелёного к красному | от безопасности к критическому состоянию |
| **Любопытство** | 0.0 | 1.0 | от серого к фиолетовому | от безразличия к исследованию |

### 3.2 Цикл обновления

```
Ввод пользователя
    ↓
agent.step() с сигналами награды, новизны и конфликта
    ↓
выполняются методы affect_state.update_from_*()
    ↓
вызывается GUI.update_affect_display()
    ↓
полосы Canvas обновляются новыми цветами и положениями
    ↓
текстовые метки обновляются числовыми значениями
    ↓
пользователь видит изменения состояния в реальном времени
```

### 3.3 Отрисовка Canvas

Каждый индикатор использует Canvas tkinter для:
- Плавных цветовых градиентов
- Динамического размера по диапазону значений
- Обновлений в реальном времени без мерцания
- Реакции на изменение размера окна
