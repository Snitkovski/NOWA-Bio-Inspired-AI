## Состояние: завершено

Графический интерфейс NOWA-Cognitive полностью перестроен для новой когнитивной архитектуры, в которой поведение возникает через консолидацию во сне, а не через обучение в бодрствовании.

---

## Что изменилось

### Основной принцип
**Прежде:** обучение во время бодрствования (стиль машинного и обучения с подкреплением)
**Теперь:** обучение только во время консолидации сна (стиль когнитивной нейронауки)

### В интерфейсе

#### Удалено
- Диалоги тренировки и автотренировки (нарушают принципы NOWA)
- Визуализация весов селектора (у селектора нет весов)
- Параметры скорости обучения
- Прямая петля «обратная связь → обучение»
- Использование `SelectorTrainer`

#### Добавлено
- **Кнопка сна** — ручное управление консолидацией
- **Диалог сна** — статистика консолидации
- **Расширенный инспектор** — 5 вкладок с подробностями консолидации
- **Обратная связь по интенсивности** — опыты со значениями интенсивности
- **Отображение когнитивного состояния** — циклы консолидации, паттерны, опыты

#### Изменено
- Загрузка опытов (в гиппокамп, не прямо в кортекс)
- Отображение статистики (циклы консолидации, число паттернов)
- Визуализация памяти (разделение эпизодической и семантической)
- Обработка обратной связи (сохранение с интенсивностью, без обучения)

## Основные возможности

### 1. Бодрствование (без обучения)
```
User Input → Agent.step() → Store Experience (immutable)
                               ↓
                         No selector learning!
```

### 2. Консолидация во сне (единственное обучение)
```
Click 🌙 Sleep → Configure cycles → Consolidate experiences
                                    ↓
                            Cluster similar experiences
                                    ↓
                            Create semantic patterns
                                    ↓
                            Forget unstable traces
                                    ↓
                        Behavior EMERGES from patterns!
```

### 3. Механизм обратной связи
```
User rates 😞-😍 → Converts to intensity (0.2-1.0)
                          ↓
                    Stores experience
                          ↓
                  "Use 🌙 Sleep for learning"
                          ↓
                    Will consolidate in sleep
```

### 4. Вкладки инспектора
1. **Эпизодическая память** — опыты в гиппокампе
2. **Семантическая память** — паттерны, созданные сном
3. **Выбор действия** — на основе давления (без весов)
4. **Консолидация** — подробности конвейера сна
5. **Статистика** — общее когнитивное состояние

## Основной принцип NOWA

### Вопрос
«Если селектор заморожен и агент получает новый опыт, изменится ли поведение?»

### Ответ NOWA
**Да, через консолидацию во сне:**

1. Новые опыты поступают в гиппокамп (неизменяемые)
2. У селектора нет весов (его нельзя «заморозить» обучением)
3. Сон консолидирует опыты в паттерны
4. Выбор использует активацию гиппокампа и паттерны
5. Поведение возникает из консолидации

### Подтверждение в интерфейсе
- У селектора нет атрибута `weights`
- У селектора нет метода `learn()`
- Всё обучение происходит в `SleepManager`
- Паттерны появляются только после сна
- Счётчик циклов консолидации нарастает
