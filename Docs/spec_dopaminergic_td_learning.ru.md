## 3. Функциональные требования

### 3.1 Вычисление ошибки временной разности

```
δt = rt + γ * V(st+1) − V(st)
```

Где:

- `r_t` — реальная награда
- `V(s)` — ценность состояния
- `γ` — коэффициент дисконтирования

### 3.2 Разделение фазического и тонического

Слой временной разности обязан разделять:

| Компонент       | Роль                      |
|-----------------|---------------------------|
| `phasic_delta`  | быстрый всплеск или провал |
| `mean_phasic`   | скользящее отфильтрованное фазическое среднее |
| `tonic_level`   | медленный дрейф базовой линии |

- Тонический уровень регулируется CER
- Фазический — мгновенная ошибка предсказания

### 3.3 Знаковая логика дофамина

- `δ > 0` → всплеск → усиление пути Go
- `δ < 0` → провал → усиление пути NoGo

**Нельзя:**

- брать абсолютное значение
- игнорировать знак

### 3.4 Взаимодействие с BG

Слой временной разности не выбирает действия. Он:

- обновляет синаптические веса
- модулирует скорости обучения Go/NoGo

### 3.5 Взаимодействие с ACC

ACC использует `|δ|` как `error_likelihood` и окно истории для конфликта.

Слой временной разности должен отдавать:

```json
{
    "phasic_delta": "δ",
    "abs_delta": "abs(δ)",
    "delta_sign": "sign(δ)"
}
```

## 4. Ограничения (системные ограничения)

### 4.1 Никакого прямого изменения награды

Слой временной разности не имеет права:

- переписывать `r_t`
- масштабировать награду постфактум

> Награда — внешний сигнал среды.

### 4.2 Никакого вмешательства в гиппокамп

Не менять:

- новизну
- завершение паттерна

### 4.3 Потолок насыщения

Фазическая дельта должна быть ограничена:

```
δ_clipped = clamp(δ, −δ_max, +δ_max)
```

> Иначе обучение уходит в разгон.

### 4.4 Ограничение устойчивости

Скорость обучения должна зависеть от `ACC learning_boost` и `CER stress_level`, но **не** напрямую от величины `δ`.

## 6. Обновление функции ценности

```
V(st) ← V(st) + α * δ_clipped
```

Где:

```
α = base_alpha × acc_learning_boost
```

## 7. Связь с исследованием

**Положительный всплеск:** слегка снижает исследование (растёт уверенность).

**Отрицательный провал:** увеличивает исследование.

Ограничение:

```
exploration modulation ≤ 0.2 от baseline
```

## 8. Тест-кейсы

### 8.1 Положительный сюрприз

**Вход:** `reward = 10`, `V(st) = 2`, `V(st+1) = 4`, `γ = 0.9`

**Ожидается:** `δ > 0`, всплеск > 0, обучение Go усилено.

### 8.2 Отрицательный сюрприз

**Вход:** награда ниже ожидания.

**Ожидается:** `δ < 0`, провал, усиление NoGo.

### 8.3 Нулевая ошибка

**Вход:** награда совпадает с ожиданием.

**Ожидается:** `δ ≈ 0`, нет всплеска и провала, тонический уровень остаётся устойчивым и меняется только медленно.

### 8.4 Насыщение большой ошибки

**Вход:** экстремальная награда.

**Ожидается:** `δ_clipped ≤ δ_max`, обучение не взрывается.

### 8.5 Повторная отрицательная серия

Несколько шагов подряд `δ < 0`.

**Ожидается:** ACC получает высокий `abs_delta`, ACC усиливает делиберативный режим, слой временной разности не уходит в разгон.

### 8.6 Модуляция стрессом CER

Если стресс CER высок: `learning_rate` уменьшается, величина всплеска не растёт.

## 9. Метрики успеха

После внедрения:

- Сходимость ценности устойчива
- Нет колебательного взрыва
- Исследование адаптивно
- ACC получает корректный сигнал ошибки
- Политика BG становится более стабильной

---

## 10. Риски

### 10.1 Положительная обратная связь

Всплеск временной разности ведёт к усилению обучения, которое ведёт к ещё большему всплеску.

**Решение:** ограничить `learning_boost`, обрезать `δ`.

### 10.2 Катастрофическое забывание

Если `γ` слишком низок, агент станет миопическим.

### 10.3 Усиление конфликта

Большие `δ` переводят ACC в постоянную делиберацию.

**Решение:** сглаживать `abs_delta` через экспоненциальное скользящее среднее.

## 11. Что изменится системно

После фазы 4 архитектура станет **саморегулирующимся организмом подкрепления**:

```
Hippocampus  →  memory + novelty
CER          →  affective tone
ACC          →  control arbitration
BG           →  action gating
Dopamine     →  plasticity engine
```

Это полноценная замкнутая адаптивная архитектура обучения с подкреплением.
