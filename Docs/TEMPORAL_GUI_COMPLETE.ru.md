## Что реализовано

### 1. Панель интерфейса: «Временные уровни»

**Добавлена в:** правую панель `src/gui.py` (после аффективного состояния, перед статистикой)

**Состав:**
- **T0 (мгновение):** текущее мгновенное аффективное состояние
  - обновляется на каждом шаге агента
  - показывает: валентность, возбуждение, угрозу, любопытство

- **T1 (тренд):** краткосрочный тренд по окну из 10 элементов
  - показывает приращения относительно T0 (знаки «плюс» и «минус»)
  - выявляет направление эмоциональной траектории
  - индикатор окна (0/10 → 10/10)

- **T2 (базовая линия):** консолидированный среднесрочный ориентир
  - медленный дрейф в бодрствовании; стабилизация после консолидации сна
  - представляет «выученное» эмоциональное состояние

- **T3 (аттрактор):** долгосрочные поведенческие аттракторы
  - очень медленная эволюция
  - представляет выученное личностное смещение

### 2. Метод обновления: `update_temporal_display()`

**Место:** `src/gui.py`, строки 430–471

**Функция:**
- извлекает временные уровни из `agent.temporal.get_levels()`
- форматирует T0 как абсолютные значения
- форматирует T1 как относительные приращения
- обновляет подписи на экране в реальном времени
- обрабатывает ошибки без обрыва

**Вызывается из:**
- `process_input()` после каждого взаимодействия с пользователем (строка 495)
- обратного вызова консолидации сна (строки 1317–1318)

### 3. Визуальное устройство

**Цветовая схема:**
```

```

**Формат отображения:**

```python
def update_temporal_display(self):
    """Обновить визуализацию временных уровней (T0/T1/T2/T3)"""
    levels = self.agent.temporal.get_levels()
    
    # Format and display each level
    t0 = levels.get('T0', {})
    t1_mean = levels.get('T1_mean', {})
    t2 = levels.get('T2_baseline', {})
    t3 = levels.get('T3_attractor', {})
    
    # Calculate T1 deltas from T0
    t1_val_delta = t1_mean.get('valence', 0) - t0.get('valence', 0)
    # ... similar for arousal, threat, curiosity
    
    # Update display labels
    self.t0_display.config(text=f"val:{t0_val:.2f} ...")
    self.t1_display.config(text=f"val:{t1_val_delta:+.2f} ...")
    # ... update T2, T3, window indicator
```

## Интеграция с существующей системой

### Архитектура
```
GUI Layer
  └─ update_temporal_display()
       └─ agent.temporal.get_levels()
            ├─ T0 (current snapshot)
            ├─ T1 (10-item window mean)
            ├─ T2 (consolidated baseline)
            └─ T3 (long-term attractor)

Agent Layer
  ├─ step() → temporal.log(snapshot) → T0/T1 updated (T2 drifts when T1 window full)
  └─ sleep() → temporal.sleep() → T2/T3 updated
```

### Обратная совместимость
- ломающих изменений нет
- отображение необязательно (мягкая деградация, если временной модуль отсутствует)
- все прежние возможности без изменений
- набор тестов полностью совместим
