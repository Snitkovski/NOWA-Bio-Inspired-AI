## 1. Цель плана B

Ввести **временную глубину поведения** без:
- градиентов
- планирования будущего
- символических целей

Результат плана B:
- агент начинает различать **последовательности**
- появляется **задержанная ценность**
- формируется **протостратегия** (стратегичность без прогнозов)

---

## 2. Базовое понятие: временная цепь

### 2.1 Определение

**Временная цепь** — это связка:

```
(context₁ → action₁) → (context₂ → action₂) → … → outcome
```

Свойства:
- конечная длина (3–7 шагов)
- не хранит цель
- не хранит ожидаемый результат
- знает только: «чем это обычно заканчивается»

---

## 3. Новая сущность: ChainMemory

### 3.1 Структура

```python
class TemporalChain:
    events: List[Event]
    net_affect: Dict[str, float]
    stability: float
    usage_count: int
```

- `events` — последовательность контекста и действия
- `net_affect` — интеграл T1/T2 на выходе цепи
- `stability` — устойчивость результата
- `usage_count` — сколько раз цепь переживалась

---

## 4. Формирование цепей (без обучения)

### 4.1 Во время бодрствования

- агент хранит **скользящее окно** последних N шагов
- каждый шаг добавляется как `(context, action, affect_snapshot)`
- окно не анализируется

### 4.2 Во сне (ключевой момент)

Только во сне:
1. окно режется на подпоследовательности
2. подпоследовательности группируются по форме
3. вычисляется `net_affect` на конце
4. создаются или обновляются временные цепи

Никакой оптимизации. Только статистика.

---

## 5. Назначение кредита без градиентов

### 5.1 Принцип

> «Хорошо или плохо — не действие, а **чем это закончилось**»

### 5.2 Механизм

- итоговый аффект (T1/T2) распределяется **назад по цепи**
- с экспоненциальным затуханием

```text
step −1: 1.0
step −2: 0.6
step −3: 0.3
```

Это **не распространение подкрепления**, а ретроспективная корреляция.

---

## 6. Использование цепей при выборе действий

### 6.1 Селектор (расширение)

При выборе действия:
1. стандартный `ActionSelector`
2. если есть подходящие временные цепи:
   - добавляется **смещение**, пропорциональное `net_affect`

Важно:
- цепи **не приказывают**
- они слегка склоняют выбор

---

## 7. Протостратегия (что это и чего это не является)

### 7.1 Что появляется

- предпочтение последовательностей
- избегание цепей с плохим концом
- повторяемые «маршруты поведения»

### 7.2 Чего не появляется

- цели
- планы
- ожидания будущего
- самоописание стратегии

Стратегия **проявляется**, но не моделируется.

|------|----------------|
| T0 | не используется |
| T1 | локальный исход цепи |

## 9. Ограничения (критично)

Запрещено:
- использовать будущие шаги
- использовать прогноз
- использовать цели
- усиливать цепи без сна

Если что-то из этого появляется, план B считается нарушенным.

## 10. Тесты плана B

### Тест 1 — Отложенная ценность

- A → B → C → хорошо
- A → D → плохо

Ожидание:
- агент со временем чаще выбирает B после A

---

### Тест 2 — Контекстная стратегия

Ожидание:
- цепи различаются

---

### Тест 3 — Без сна

- длинная сессия
- без сна

Ожидание:
- цепи не формируются
