## Двухуровневая пластичность (актуальное ядро)

В `src/` **лабильные метки** пишутся днём и затухают; **стабильные параметры** — только в `Agent.sleep()`. Выбор по stable + labile. Хост передаёт `dt` / `advance_time`, задаёт `expected_wake_interval_s` и вызывает `sleep()`.

Справочник: [two-tier-plasticity.ru.md](../docs/architecture/two-tier-plasticity.ru.md), [SLEEP.ru.md](SLEEP.ru.md), [спека #13](../docs/specs/issue-13-two-tier-plasticity.md). Разделы ниже — устаревший tutorial по весам селектора, не контракт ядра.

## Two-tier plasticity (current core)

The `Agent` separates labile (waking) and stable (sleep-only) learning. See [two-tier-plasticity.en.md](../docs/architecture/two-tier-plasticity.en.md) and [SLEEP.en.md](SLEEP.en.md). Sections below are legacy GUI material.

## Как это работает?

### 1. **Архитектура системы**

```
┌─────────────────────────────────────────────┐
│            NOWA Agent                        │
├─────────────────────────────────────────────┤
│ Входные данные: "кто ты"                    │
│         ↓                                    │
│ ┌──────────────────────────────────────┐    │
│ │ Гиппокамп (Episodic Memory)          │    │
│ │ Хранит конкретные опыты с наградой   │    │
│ └──────────────────────────────────────┘    │
│         ↓                                    │
│ ┌──────────────────────────────────────┐    │
│ │ Селектор действий (Action Selector)  │    │
│ │ Выбирает лучшее действие             │    │
│ │ на основе:                           │    │
│ │ • Весов действий (обучение)          │    │
│ │ • Активных опытов (память)           │    │
│ └──────────────────────────────────────┘    │
│         ↓                                    │
│ Выходные данные: "Я NOWA..."                │
└─────────────────────────────────────────────┘
```

### 2. **Загрузка опыта из датасета**

Когда вы загружаете датасет (например, `dialog_experience.json`):

```json
[
  {
    "context": "как дела",
    "action": "сказать_привет",
    "reward": 1.0
  },
  {
    "context": "кто ты",
    "action": "ответить_кто_я",
    "reward": 1.0
  }
]
```

**Система преобразует это в:**

```python
# Experience #1
Context: "user:как дела"
Action: "action:сказать_привет"
Reward: 1.0
↓ Сохраняется в гиппокампе
```

### 3. **Как выбирается действие?**

При вводе "кто ты":

1. **Активация**: Гиппокамп находит все опыты, которые содержат контекст "user:кто ты"
2. **Оценка**: Для каждого возможного действия вычисляется score:
   - `score = вес_действия + бонус_из_опытов`
3. **Выбор**: Селектор выбирает действие с максимальным score

```python
Scores:
  ответить_кто_я:  0.5 + 0.8 (бонус) = 1.3  ← ВЫБРАНО
  сказать_привет:  0.4 + 0.0           = 0.4
  отказаться:      0.3 + 0.0           = 0.3
  помочь:          0.2 + 0.0           = 0.2
```

### 4. **Обучение на основе оценок**

Когда вы даете оценку (пять звёзд):

```
Оценка = +2
↓
reward += 2 * alpha (обычно 0.1)
↓
Вес "ответить_кто_я" увеличивается на 0.2
↓
Следующий раз это действие будет выбранного чаще
```

### 5. **Автоматическая тренировка селектора**

Система может самостоятельно обучаться на датасете!

```
Датасет
  ↓
Для каждого опыта:
  ├─ Активируем контекст
  ├─ Выбираем действие селектором
  ├─ Сравниваем с правильным из датасета
  ├─ Даем награду если совпадает (+1.0)
  └─ Даем штраф если не совпадает (-1.0)
  ↓
Веса действий обновляются
  ↓
Повторяем несколько эпох
  ↓
Accuracy повышается!
```

**Как использовать:**
1. Загрузите датасет (кнопка "Загрузить датасет")
2. Нажмите "Авто-тренировка"
3. Установите параметры:
   - **Количество эпох**: 5-10 обычно достаточно
   - **Скорость обучения**: 0.5 — балансирует скорость обучения
4. Нажмите "Начать тренировку"
5. Смотрите результаты — точность должна расти!

### 6. **Почему система работает по-разному для разных вопросов?**

- **Вопрос: "кто ты?"** → Активирует опыт про "ответить_кто_я" → Дает ответ про NOWA
- **Вопрос: "как дела?"** → Активирует опыт про "сказать_привет" → Дает ответ про приветствие
- **Вопрос: "помоги мне"** → Активирует опыт про "отказаться" → Дает уклончивый ответ

## Как исправить проблемы?

### Проблема: Все ответы одинаковые
**Решение**: 
1. Используйте "Авто-тренировка" чтобы селектор научился различать контексты
2. Или дайте много оценок вручную (звездочки)

### Проблема: Система не учится на оценках
**Решение**: Убедитесь что вы даете оценки через кнопки со звездами в интерфейсе

### Проблема: Опыты не влияют на выбор
**Решение**: 
1. Используйте "Авто-тренировка" для быстрого обучения
2. Или используйте "Обновить" в окне "Тренировка" чтобы увидеть статистику

## Структура датасета

```json
[
  {
    "context": "строка или список контекста",
    "action": "одно из возможных действий",
    "reward": число (положительное = хорошо, отрицательное = плохо)
  }
]
```

**Важно**: 
- Положительные награды укрепляют действие
- Отрицательные награды ослабляют действие
- Система предпочитает опыты с положительными наградами при выборе

## Архитектурные компоненты

### `experience.py`
- `Event`: Событие с временной меткой
- `Path`: Последовательность событий
- `Experience`: Опыт с путем и наградой

### `hippocampus.py`
- `NOWAHippocampus`: Эпизодическая память
- Хранит конкретные опыты
- Активирует опыты по контексту

### `selector.py`
- `ActionSelector`: Выбор действий
- Использует веса и опыты для выбора
- Обучается через метод `learn()`

### `trainer.py` (новое)
- `SelectorTrainer`: Автоматическая тренировка
- `train_epoch()`: Один проход по датасету
- `train_full()`: Множество эпох
- `get_accuracy()`: Вычисляет точность

## Функциональность графического интерфейса

- **Загрузить датасет**: Загружает опыты из JSON
- **Тренировка**: Показывает статистику загруженных опытов
- **Авто-тренировка**: Селектор сам себя тренирует на датасете
- **Инспектор**: Показывает детальную информацию о памяти
- **Сохранить/Загрузить**: Сохраняет состояние агента
