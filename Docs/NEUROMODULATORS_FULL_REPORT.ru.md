## I. Исходное техническое задание

### Источник
Файл: `Docs/NOWA_Neuromodulators_Plan.md`

### Требования
Реализовать 4 независимых нейромодулятора:
1. **Dopamine (DA)** — усиление паттернов обучения
2. **Norepinephrine (NE)** — формирование причинных цепочек
3. **Serotonin (5-HT)** — стабилизация памяти
4. **Cortisol (CORT)** — агрессивное забывание нестабильного

### Принципы
- ❌ БЕЗ субъективных переживаний
- ✅ Только модуляция обучения
- ✅ Применение во время консолидации сна
- ✅ Сохранение обратной совместимости

### B. Алгоритм обновления

```
Во время Agent.step():
  1. Получить reward, novelty, conflict от среды
  2. Вызвать neuromodulators.update_from_signals(reward, novelty, conflict)
  3. Применить сигнальные коэффициенты:
     - DA += 0.2 * reward (если reward > 0)
     - DA -= 0.1 * abs(reward) (если reward < 0)
     - NE += 0.3 * novelty
     - CORT += 0.15 * conflict
     - CORT += 0.05 * abs(reward) (если reward < 0)
     - 5-HT += 0.01 (если все signals ~= 0)
  4. Применить decay: nm *= exp(-0.01 * elapsed_time)
  5. Нормировать: clamp(nm, 0.0, 1.0)

Во время Agent.sleep():
  1. Выполнить стандартную консолидацию памяти
  2. Вызвать _apply_neuromodulators_during_sleep()
  3. Для каждого нейромодулятора применить эффект:
     - DA: усилить strength паттернов (+5%)
     - NE: создать цепочки от последних опытов (max 9)
     - 5-HT: повысить stability опытов (+1%)
     - CORT: повысить порог забывания (+20%)
```

```
**Причина:** Параметр в docstring, но не в сигнатуре функции  
**Решение:** Добавить `neuromodulators=None` в строке 17  
**Статус:** ✅ Исправлено

```

**Статус:** ✅ Исправлено

## IX. Ограничения и предостережения

### Текущие ограничения

1. **Нет синергии между нейромодуляторами** — они действуют независимо
2. **Фиксированные коэффициенты влияния** — не адаптируются во времени
3. **Нет предсказания состояния** — управление реактивное, не проактивное
4. **Применение только во время сна** — нет прямого влияния на выбор действия

### Известные особенности

- Начальное состояние нейромодуляторов: DA=0.1, NE=0.1, 5-HT=0.1, CORT=0.05
- Декаimiento происходит с периодом полувывода ~70 итераций
- Эффекты могут быть незаметны при редком сне (sleep_cycle < 1 в 10 шагов)
