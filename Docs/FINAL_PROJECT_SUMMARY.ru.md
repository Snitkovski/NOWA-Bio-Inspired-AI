### Цветовая Кодировка
- 🔴🟢 Валентность: Red ← → Green (Грустный ← → Счастливый)
- 🔵🟠 Возбуждение: Blue ← → Orange (Спокойный ← → Гиперактивный)
- 🟢🔴 Угроза: Green ← → Red (Безопасно ← → Критично)
- ⚫🟣 Любопытство: Gray ← → Purple (Безразличен ← → Исследует)
