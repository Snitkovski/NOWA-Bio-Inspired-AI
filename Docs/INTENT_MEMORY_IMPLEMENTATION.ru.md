**Файл:** `src/intent_memory.py` (191 строка)

Создано:

- `IntentTrace` — одна привычка (intent + context)
- `IntentMemory` — коллекция привычек, формирование/активация/деградация

- `record_trace(context, intent)` — записать привычку

## Архитектура

```
Context
  ↓
[IntentMemory] ← Формирует привычки из опыта
  ↓ (давление привычки)
[Selector + ActionIntent] ← Выбирает действие
  ↓
[Hippocampus] ← Записывает опыт
  ↓ (во время сна)
[Cortex + IntentMemory degrade] ← Консолидирует
  ↓
[ActionRealizer] ← Выбирает форму
  ↓
Output
```

### Ключевое свойство

> **IntentMemory создаёт давление, но не выбирает действие.**

- Собирает данные о том, какие действия обычно выбираются
- Передаёт это давление селектору
- Селектор использует давление, но может выбрать что-то иное
- **Нет обучения, нет весов, нет оптимизации**

### Структура IntentTrace


## Цикл жизни

### Формирование

```
1. Agent.step() выбирает действие
2. intent_memory.record_trace(context, action)
3. Если (context, action) первый раз:
   - создать новый trace (strength=1.0)
4. Если был раньше:
   - усилить trace (strength += 1.0)
   - обновить timestamp и recency
```

### Активация

```
1. Selector.choose() запрашивает действие
2. Agent вызывает intent_memory.activate_by_context(context)
3. IntentMemory:
   - вычисляет context_signature
   - находит все matching traces
   - обновляет recency (exponential decay)
   - вычисляет pressure = strength × recency
   - возвращает {intent: pressure}
4. Selector использует это давление при выборе
```

### Консолидация (во время сна)

```
1. SleepManager.sleep_cycle() запускается
2. Вызывает intent_memory.degrade_unused(decay_factor=0.8)
3. IntentMemory:
   - умножает strength каждого trace на decay_factor
   - удаляет traces с strength < min_threshold
4. Результат: слабые привычки забываются, сильные остаются
```

## Критерии успеха

Все критерии из плана выполнены:

- **нет if/else по действиям** (используется давление привычек)
- **нет жёстких строк ответов** (ActionRealizer выбирает из памяти)
- **новые формы появляются через опыт** (traces создаются автоматически)
- **старые формы деградируют** (во время сна ослабевают)
- **привычки формируются из опыта** (`record_trace`)
- **нет обучения селектора** (только давление, не весы)
- **система стабилизируется** (`confidence` растёт при повторении)
- **система сомневается при конфликте** (`confidence` < 0.7)

## Архитектурное место

IntentMemory — **второй слой** системы выбора действий:

```
Уровень 1: Состояние (Context)
Уровень 2: IntentMemory ← (я) Привычки
Уровень 3: Selector → ActionIntent
Уровень 4: Hippocampus → Experience
Уровень 5: ActionRealizer → Output форма
Уровень 6: Sleep → Консолидация
```

Система **трёхслойная по выбору:**

1. **Привычки** (IntentMemory) — создают давление
2. **Опыт** (Hippocampus) — создают давление
3. **Паттерны** (Cortex) — создают давление

**Селектор** использует все три давления для выбора.

## Дальнейшее развитие

Возможные улучшения (не нарушающие принцип отсутствия обучения):

1. **Оконный контекст** — учитывать историю контекста, а не только последнее событие
2. **Различные скорости затухания** — разный период полураспада для разных типов интентов
3. **Эмоциональная интенсивность** — интенсивность опыта влияет на скорость формирования и деградации
4. **Периодическое подкрепление** — периодическое укрепление важных привычек без явного обучения
5. **Сходство контекстов** — активировать похожие контексты с меньшим давлением

## Итог

**IntentMemory успешно реализована как:**

- система формирования привычек из опыта
- механизм передачи давления селектору
- часть консолидации во сне (деградация)
- полностью протестированный компонент (30/30 тестов)
- задокументированный компонент
- продемонстрированный компонент

**Система по-прежнему не имеет обучения:**

- Нет весов
- Нет оптимизации
- Нет градиентов
- Поведение возникает из памяти, а не из целевой функции

**NOWA теперь работает с тремя слоями давления на селектор:**

1. Недавний опыт (гиппокамп)
2. Привычки (`intent_memory`)
3. Консолидированные паттерны (кора)
