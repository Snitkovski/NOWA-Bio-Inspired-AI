## Следующие Шаги

1. **Обновить все ссылки** в коде (если они были в корне)
2. **Проверить импорты** - убедиться, что ничего не сломалось
3. **Запустить тесты** - проверить целостность
4. **Закоммитить изменения** в git

```bash
# Проверка тестов
cd e:\git\NOWA-Cognitive
pytest tests/ -v

# Если всё OK, коммит
git add .
git commit -m "chore: reorganize project structure - move docs to Docs/ and tests to tests/"
git push
```
