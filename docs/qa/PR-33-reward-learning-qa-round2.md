## Дефекты

Новых нет.

Статус прошлого круга:

1. Ревизия rating затирала Q — исправлено. Поправка считается от текущего Q (`stored + новый backup − старый backup`).
2. Повтор того же feedback двигал Go/NoGo и привычку — исправлено. Совпадающий уже закоммиченный rating выходит до этих обновлений.
3. `step(reward=...)` не учил привычку и канал — исправлено. Общий путь `_record_known_outcome`.
4. NaN/inf обрывали `step` — исправлено. NaN считается неизвестным исходом, ±inf зажимается в ±1 до записи в гиппокамп.
5. После save/load id `ep-1` переиспользовался — исправлено. Счётчик пишется в save и при отсутствии ключа восстанавливается по наибольшему `ep-N`. Повторный id не отбирает уже записанный эпизод.
6. `rng_seed` не управлял softmax таламуса — исправлено. При переданном `rng_seed` `ThalamicGate.select` берёт `self._rng`.
7. Докстринги описывали старые формулы — исправлено. В `process` NoGo канала, в `Agent` бодрствующий TD.
