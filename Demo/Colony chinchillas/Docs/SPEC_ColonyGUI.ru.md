# Спецификация: графический интерфейс колонии (текущая реализация)

English version: [SPEC_ColonyGUI.en.md](SPEC_ColonyGUI.en.md)

## Аннотация

Научное описание колонии: [COLONY_SPEC.ru.md](COLONY_SPEC.ru.md).

Документ описывает текущую реализацию графического слоя `colony_gui` как представление только для чтения над `SimulationRunner`. Слой считывает снимок состояния, строит данные отрисовки — положения, анимации, статистику наблюдателя и ресурсы — и исполняет демонстрационный цикл, в том числе в режиме без окна. Выбор действия агента и когнитивная логика NOWA остаются вне этого слоя.

Спецификация фиксирует точки входа, состав модулей сцены и панелей, канонический формат имени особи, детерминированное размещение по зонам клетки с ограничениями вместимости и согласованность анимации колеса с владельцем блокировки. Визуальная зона по умолчанию следует положению агента, чтобы отображение не вносило самостоятельных перемещений. Отдельно заданы кэширование статичной сцены, ограничение шага кадра и адаптивный шаг симуляции, а также порядок разрешения каталогов спрайтов и звука.

В колониальной установке данный слой выполняет функцию воспроизводимого наблюдения: демографические и поведенческие события остаются привязанными к состоянию симуляции, а интерфейс не подменяет контур принятия решений. Спецификация отделяет презентацию колонии от модели особи и задаёт условия, при которых визуальный протокол не искажает пространственную и ресурсную динамику многоагентной системы.

## 1. Назначение

`colony_gui` — слой представления только для чтения над `SimulationRunner`.

Слой выполняет:
- чтение данных снимка из бегунка;
- построение состояния отрисовки (положения, анимации, статистика наблюдателя, ресурсы);
- цикл демонстрации pygame и режим без окна.

Слой не выполняет:
- решение о поведении агента;
- подмену выбора действия NOWA;
- изменение ядерной когнитивной логики.

## 2. Точки входа

Весь исполняемый код находится в `src`.

Основные средства запуска:
- `src/gui.py` (рекомендуется)
- `python -m colony_gui` через `src/colony_gui/__main__.py`

Примеры:

```bash
cd "Demo/Colony chinchillas/src"
python gui.py --agents 4
python gui.py --headless --agents 4 --duration 5
python -m colony_gui --agents 6
```

## 3. Файлы интерфейса

- `src/colony_gui/colony_gui.py`: модель чтения снимка, построитель состояния отрисовки, скорость и пауза, обёртки сохранения и загрузки, `population_stats`.
- `src/colony_gui/app.py`: цикл pygame, отрисовка сцены, сглаживание, адаптивный тайминг, звуковые эффекты, сводная панель статистики.
- `src/colony_gui/config.py`: константы отрисовки, координаты зон, отображение действия в анимацию и звук, помощники формата имени.
- `src/colony_gui/cage_view.py`: детерминированное размещение слотов зоны.
- `src/colony_gui/agent_panel.py`: модель данных карточки.
- `src/colony_gui/detail_popup.py`: модель подробных сведений об агенте.
- `src/colony_gui/interaction_overlay.py`: извлечение недавних социальных взаимодействий.

## 4. Формат имени агента

Канонический формат отображения:

`G<generation>A<index_in_generation>S<sex>`

Примеры:
- `G0A1SM`
- `G2A5SF`

Правила:
- регулярное выражение: `^G[0-9]+A[0-9]+S[MFU]$`
- порождается функцией `format_agent_name(generation, index_in_generation, sex)`
- если исходное имя уже каноническое, оно сохраняется
- устаревшие имена `GxAy` в интерфейсе дополняются суффиксом пола

## 5. Размещение по зонам и занятость

Зоны отрисовки задаются `ZONE_RENDER_COORDS`.

Стратегия размещения:
- у каждой зоны есть детерминированные смещения слотов;
- переполнение использует детерминированное дрожание на основе `agent_id`;
- неизвестные зоны отступают к `floor`.

Исключительная визуальная вместимость:
- `wheel: 1`
- `dustbath: 1`

Если вместимость исчерпана, интерфейс использует запасные зоны из `_pick_capacity_fallback(...)`.

## 6. Согласованность колеса

Отрисовка колеса учитывает блокировку:
- спрайт бега в колесе допустим только для владельца блокировки колеса;
- если владельцем блокировки является другой агент, не-владелец не может быть отрисован как бегущий в колесе;
- идентификатор анимации колеса понижается до анимации ходьбы, когда визуальная зона не равна `wheel`.

Это исключает артефакт, при котором несколько агентов бегут в одном колесе.

## 7. Политика разрешения визуальной зоны

Текущая политика в `app.py`:
- по умолчанию визуальное размещение согласовано с `agent.position` симуляции;
- для стандартных действий не навязываются независимые перемещения интерфейса;
- таблица подсказок действий сохраняется для совместимости и управляемого запасного поведения.

Это исключает конфликт движения интерфейса и движения агента.

## 8. Производительность и плавность

Реализованные оптимизации:
- кэш статичной сцены клетки (`static_scene`);
- кэши спрайтов и звуковых клипов;
- кэши поверхностей имени и текста панели;
- очистка устаревшего кэша при исчезновении агентов;
- ограниченная дельта кадра (`MAX_FRAME_DT_S`);
- ограниченный шаг сглаживания (`_smooth_position_step`);
- адаптивный размер шага симуляции по числу агентов и экспоненциальному скользящему среднему стоимости такта;
- ограничение шагов догона, чтобы избежать спирального замедления.

## 9. Ресурсы

Ресурсы по манифесту:
- манифест спрайтов: `manifest.json`
- манифест звука: `sfx_manifest.json`

Порядок разрешения каталогов (`resolve_assets_dir`):
1. `Demo/Colony chinchillas/assets/<kind>`
2. `Demo/Colony chinchillas/<kind>`
3. `Demo/Tamagochi Chinchilla/<kind>` (устаревший запасной путь)

## 10. Панель состояния и управление

В текущем цикле pygame:
- `SPACE`: пауза и продолжение
- `+` / `-`: ускорение и замедление
- `M`: звук включён или выключен
- `ESC`: выход

Раскладка интерфейса:
- клетка рисуется внутри `CAGE_RECT`;
- одна сводная панель рисуется ниже границы клетки (не поверх клетки);
- панель использует русские подписи и полосовые индикаторы.

Содержание панели:
- строка 1: `Время`, численность (`самок/самцов`), средний возраст;
- строка 2: `Половозрелые`, `Эструс`, `Беременные`, `Рождений/смертей`, `Связи/крепкие пары`;
- ряд полос 1: `Стресс`, `Энергия`, `Сплоченность`, `Риск вымирания`;
- ряд полос 2: уровни ресурсов `Корм`, `Сено`, `Вода`;
- строка 3: состояние скорости, паузы и звука и привязки клавиш.

Примечание к интерпретации:
- `estrus` — мгновенный живой счётчик (`heat_cycle.phase == "estrus"`).
- визуальное социальное скопление у корма и сена не означает успешного спаривания.
- сердца спаривания рисуются только когда оба агента находятся в `mount_display` и взаимно связаны через `_current_mate_id`.
