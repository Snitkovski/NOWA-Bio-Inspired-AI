# Лексическая валидация: научное описание установки

English version: [SCIENTIFIC_DESCRIPTION.en.md](SCIENTIFIC_DESCRIPTION.en.md)

### 1. Предмет

Установка сопоставляет аффективный отклик колонии суверенных агентов NOWA с человеческими нормами аффективного значения слова. Эталон — оценки валентности и возбуждения Warriner, Kuperman, Brysbaert (2013), поле `V.Mean.Sum` для валентности. Вопрос прогона: согласован ли средний сдвиг валентности колонии с рангом человеческой нормы.

Научное описание комплекса: [SCIENTIFIC_DESCRIPTION.ru.md](../../../Docs/SCIENTIFIC_DESCRIPTION.ru.md). Контракт реализации — `NOWA_Warriner_Validation_Spec_2.1.md` и предшествующая спецификация того же каталога.

### 2. Метод

Среда переводит слово в контекстные события и подаёт их каждому агенту отдельно. Каждый агент выполняет собственный `step`. Среда читает публичное состояние после шага и агрегирует сдвиги. Общей памяти, общей шины команд и центрального контроллера нет. Посев гиппокампа, если он выполняется, применяется к каждому агенту по отдельности; порядок корпуса для агента перемешивается его генератором.

Зависимые величины: средний сдвиг валентности колонии и средний сдвиг возбуждения. Меры связи с нормой: ранговая корреляция Спирмена, коэффициент Пирсона и конкордантная корреляция. Дополнительно протокол предусматривает связь сдвига дофамина и сдвига кортизола с валентной нормой. Отчёт также содержит стандартные отклонения, долю нулевой активации памяти и разложение по архетипам колонии.

Пороги, записанные в нормативной спецификации (например, границы слабого и более выраженного сигнала), суть правила протокола демонстрации. Они не являются установленной в настоящем тексте величиной корреляции. Численный итог образуется прогоном валидатора и в это описание как константа не включается.

### 3. Инварианты

1. Агент не получает стимул через общий метод колонии. Цикл обходит особей.
2. Среда не записывает внутреннее состояние агента.
3. Оси \(A(t)\) не расширяются под шкалы Уорринера. Сдвиг читается из канонического состояния.
4. Наблюдатель пассивен относительно выбора действия.

### 4. Воспроизведение

Код оркестрации: `src/nowa_validation/` (`warriner_validator.py`, `word_stimulus_encoder.py`, `nowa_colony.py`, `hippocampus_seeder.py`). Краткий запуск предусмотрен модулем `run_quick.py`, графический контур — `demo_app.py`. Проверки размещены рядом с установкой по принятому в ней расположению тестов.

### 5. Границы интерпретации

Согласованность рангов с лексической нормой есть проверка аффективного отображения, а не доказательство семантического понимания. Нулевая или слабая корреляция совместима с исправной архитектурой, если кодировщик стимула не активирует релевантные следы. Сильная корреляция на одном режиме кодировщика не переносится на другой режим без отдельного прогона.
