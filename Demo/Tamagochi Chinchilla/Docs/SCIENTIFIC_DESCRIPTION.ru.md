# Этологический агент: научное описание установки

English version: [SCIENTIFIC_DESCRIPTION.en.md](SCIENTIFIC_DESCRIPTION.en.md)

### 1. Предмет

Установка изучает выразимость архитектуры NOWA в поведении одной особи при непрерывном отображении. Наблюдаемыми величинами служат выбранное действие, его реализация в анимации и звуке, аффективное состояние и сохранение сессии. Популяция, размножение и протокольное тело в эту установку не входят.

Научное описание комплекса: [SCIENTIFIC_DESCRIPTION.ru.md](../../../Docs/SCIENTIFIC_DESCRIPTION.ru.md).

### 2. Состав действующей сборки

Когнитивные модули импортируются из ядра репозитория (`src/` корня, либо из каталога `nowa_src` при упаковке). В `src/main.py` к ним относятся, в частности, `affective_space`, `autonomous_organism` (`DriveSystem`, `EnergySystem`), `basal_ganglia`, `conflict_arbitration`, `emotional_regulation`, `hippocampus`, `neuromodulators`, `sleep`, `wakefulness`, `value_layer`, `intent_memory`, `decision_arbitrator`, `hippocampal_imagine_engine`, слои персистенции, фона, семантических эмоций, нарративов и ожиданий, а также `external_interaction_layer` и `storage`.

Локальный слой установки задаёт этологический репертуар и предъявление:

| Модуль | Функция |
|---|---|
| `behavioral_chains.py` | Поведенческие цепи |
| `demo_action_realizer.py` | Реализация намерения в параметрах анимации |
| `scheduling_system.py` | Локальный цикл потребностей; сохранён рядом с `DriveSystem` ядра |
| `memory_system.py` | Память предпочтений исходов цепей |
| `audio_system.py` | Звуковое сопровождение |
| `pygame_engine.py`, `gui.py` | Отображение |
| `dataset_loader.py`, `config.py` | Репертуар из наборов данных |

Ранние документы `PHASE2_MEMORY_SYSTEM.md` и `PHASE3_SCHEDULING_SYSTEM.md` описывают промежуточные механизмы предпочтения и цикла потребностей. `NOWA_INTEGRATION_SPEC.md` и `IMPLEMENTATION_SPEC.md` суть нормативные протоколы доработки, а не отчёт о том, что локальный планировщик удалён. Действующая сборка связывает оба контура: модули ядра и локальный этологический слой присутствуют одновременно.

### 3. Инварианты, переносимые из ядра

Каноническое аффективное состояние остаётся восьмимерным вектором ядра. Допуск действия принадлежит базальным ганглиям. Консолидация медленной памяти приурочена к циклу сна ядра. Локальная память предпочтений является дополнительным следом установки и не подменяет гиппокамп.

### 4. Воспроизведение

Точка входа организма: `Demo/Tamagochi Chinchilla/src/main.py`. Интерфейс: `src/gui.py`. Проверки: каталог `Demo/Tamagochi Chinchilla/tests`. Численные сводки тестов из ранних лабораторных заметок в настоящее описание не переносятся.

### 5. Границы

Установка демонстрирует одну особь. Демографические выводы колонии и выводы о протокольном теле к ней не относятся. Количественная оценка сходства с этологией *Chinchilla lanigera* настоящим текстом не утверждается: репертуар задан наборами данных и служит управляемой средой наблюдения архитектуры.
