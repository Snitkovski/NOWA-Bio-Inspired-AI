# Ethological Agent: Composition and Document Status

Russian version: [PROJECT_COMPLETE_SUMMARY.ru.md](PROJECT_COMPLETE_SUMMARY.ru.md)

The previous drafting of this file reported phase completion in a laboratory register and quoted a test summary of that session. The present drafting replaces it with a scientific status.

The current build is described in [SCIENTIFIC_DESCRIPTION.en.md](SCIENTIFIC_DESCRIPTION.en.md). In brief: cognitive subsystems are imported from the NOWA core; the local modules `behavioral_chains`, `demo_action_realizer`, `scheduling_system`, `memory_system`, `audio_system`, and pygame supply the repertoire and the presentation. The protocols of integration and of reward correction remain in `NOWA_INTEGRATION_SPEC.md` and `IMPLEMENTATION_SPEC.md` and are not read as evidence that the local scheduler has been removed.

Numerical claims of the earlier drafting (test counts, code volume, numbers of sounds and realisation variants) are not carried into this status: they were not rechecked in the present documentation revision.
