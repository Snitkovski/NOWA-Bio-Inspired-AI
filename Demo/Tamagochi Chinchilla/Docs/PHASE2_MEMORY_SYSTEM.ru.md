## Аннотация

Научное описание установки: [SCIENTIFIC_DESCRIPTION.ru.md](SCIENTIFIC_DESCRIPTION.ru.md).

Документ представляет отчёт о построенной локальной подсистеме обучения и консолидации памяти, образующей вторую фазу работ. Описаны запись взаимодействия с аффективным контекстом до и после поведенческой цепочки, накопление предпочтений по доле успеха, недавней успешности и убывающему бонусу новизны, а также оценка награды по изменениям, специфичным для типа цепочки, и по общему сдвигу аффективного тона. Награда ограничивается отрезком от минус единицы до единицы. Консолидация отнесена к периодам покоя; сохранение и загрузка выполняются в формате JSON с ограничением числа хранимых записей.

Отчёт фиксирует встраивание подсистемы в агента: инициализацию файла памяти, регистрацию завершённой цепочки, использование выученных весов при выборе поведения и сохранение при завершении сеанса. Приведены ёмкость журнала, интервал консолидации и порядок вычислительной стоимости основных операций. В качестве содержания следующей фазы названы циклы голода, усталости и скуки, сопряжённые с выученными предпочтениями.

В разделе покрытия отчёт перечисляет десять проверок подсистемы памяти как пройденные, пять из пяти проверок базовой функциональности как пройденные и отдельно указывает, что интеграционные проверки проходят для трёх случаев из четырёх, относя оставшийся сбой к шрифту графического интерфейса. Заключительная строка статуса сообщает о десяти пройденных проверках памяти из десяти. Указанные величины воспроизводятся как формулировки отчёта, каждая в той рубрике, в которой она приведена. Описанный контур является локальной системой MemorySystem; точка входа демонстрации импортирует её совместно с модулями когнитивного ядра.

## Обзор

Реализация фазы 2 добавляет тамагочи-шиншилле полную систему памяти и обучения. Система позволяет агенту:

1. **Учиться на исходах поведения** — отслеживать успех и неуспех разных цепочек
2. **Строить предпочтения** — вычислять выученные веса предпочтения для цепочек и взаимодействий
3. **Консолидировать память** — усиливать успешные паттерны в периоды покоя
4. **Сохранять обучение** — сохранять и загружать память для непрерывности между сеансами

## Архитектура

### Основные компоненты

#### 1. **MemoryEntry** (структура данных)
Записывает одно поведенческое взаимодействие с полным контекстом:
- метка времени и имя цепочки
- аффективные состояния до и после, с приращениями
- оценка успеха и балл награды
- сериализуемость в JSON для сохранения

#### 2. **BehaviorPreference** (структура данных)
Отслеживает выученные предпочтения цепочек и взаимодействий:
- число успехов и общее число попыток
- вычисление средней награды
- недавняя доля успеха (смещение к недавнему)
- вычисление веса предпочтения

**Формула веса:**
```
preference_weight = base_weight * adaptation_factor
where:
  base_weight = success_rate * 0.6 + recent_success_rate * 0.4
  adaptation_factor = 0.8 + novelty_bonus * 0.2
  novelty_bonus = decays with attempt frequency
```

Результат: успешные цепочки получают усиление, частые цепочки получают штраф новизны, чтобы поощрять исследование.

#### 3. **MemorySystem** (главный класс)
Управляет всеми операциями обучения:
- записывает взаимодействия с автоматической оценкой награды
- обновляет веса предпочтения цепочек и взаимодействий
- запускает консолидацию в периоды покоя
- сохраняет и загружает файлы памяти

### Вычисление награды

Система вычисляет награду по улучшению аффекта:

**Бонусы, специфичные для цепочки:**
- `eating`: +0.3, если голод снижается
- `bedtime`: +0.3, если усталость снижается
- `play`: +0.25, если скука снижается, и +0.25, если счастье растёт
- `grooming`: +0.2, если спокойствие растёт

**Общие улучшения:**
- Снижение страха и печали: +(приращение * 0.1) на единицу снижения
- Удержание счастья и спокойствия выше 0.5: +(значение * 0.05)
- Отрицательные цепочки теряют баллы за рост страха и печали

**Результат:** награды лежат в диапазоне от -1.0 до +1.0 и автоматически ограничиваются.

## Точки интеграции

### 1. Изменения ChinchillaAgent

**Инициализация:**
```python
self.memory = MemorySystem(
    memory_file=self.demo_dir / "saves" / "memory.json",
    logger=self.logger
)
```

**Выполнение шага:**
- записывает завершение цепочки после окончания поведенческой цепочки
- консолидирует память каждые 5 минут (настраивается)
- сохраняет память при очистке

**Выбор цепочки:**
- использует `get_chain_weights()` для изменения вероятностей выбора
- может взвешивать цепочки по выученным предпочтениям

### 2. Отслеживание состояния

Добавлено в `ChinchillaAgent.step()`:
```python
self.last_chain_name = chain          # For memory recording
self.chain_start_affect = affect_state # For delta calculation
```

Когда цепочка завершается:
```python
self.memory.record_interaction(
    chain_name=self.last_chain_name,
    affect_before=self.chain_start_affect,
    affect_after=current_affect,
    current_time=self.total_time
)
```

## Ключевые свойства

### 1. Осмысленная оценка награды
- автоматически оценивает исходы как успех или неуспех
- учитывает пользу, специфичную для цепочки (например, еда снижает голод)
- отслеживает общие эмоциональные улучшения
- нормирует награды в диапазон [-1, 1]

### 2. Взвешивание предпочтений
- больший вес у успешных цепочек
- смещение к недавнему: недавние успехи весят больше
- бонус новизны: часто используемые цепочки получают небольшой штраф
- результат: баланс исследования и эксплуатации

### 3. Консолидация памяти
- периодический пересмотр обучения (каждые 5 минут)
- обновление недавних долей успеха
- журнал наиболее выученных цепочек
- усиление успешных паттернов

### 4. Сохранение
```python
# Saves up to last 500 entries in JSON format
self.memory.save_memory()

# Automatically loads on next session
self.memory = MemorySystem(memory_file="saves/memory.json")
```
