## Аннотация

Научное описание установки: [SCIENTIFIC_DESCRIPTION.ru.md](SCIENTIFIC_DESCRIPTION.ru.md).

Документ представляет отчёт о построенной локальной системе планирования демонстрационного организма, образующей третью фазу работ. Описаны класс автономного цикла и управляющий класс, которые ведут три потребности — голод, усталость и скуку — с раздельными скоростями нарастания и насыщения, порогами критического и удовлетворённого состояний и ускорением усталости в период активности. К циклам присоединён циркадный ритм с периодом порядка двадцати минут симуляционного времени. Предложения драйвов комбинируются с весами, накопленными подсистемой памяти, и участвуют в отборе поведенческих цепочек, когда суммарный вес превышает указанный в отчёте порог 0,8.

Отчёт фиксирует встраивание в шаг агента: обновление циклов по активным цепочкам, перенос приращений в аффективное состояние и включение статуса циклов, драйвов и циркадной фазы в снимок состояния. В качестве поведенческих следствий описаны конкуренция потребностей и регулярности, производные от голода, активности и скуки. Приведены настраиваемые параметры циклов и перечень созданных файлов локального планировщика вместе с сопровождающими проверками.

В разделе результатов отчёт сообщает о прохождении шестнадцати проверок планировщика, шести интеграционных проверок, пяти проверок базовой функциональности и десяти проверок памяти, суммируя их как тридцать семь из тридцати семи. Эти величины приводятся как сведения самого отчёта. Описанный контур является локальной системой SchedulingSystem; точка входа демонстрации импортирует её совместно с модулями когнитивного ядра.

Реализация фазы 3 добавляет автономные аффективные циклы, которые ведут отбор поведения. Система создаёт реалистичные потребности, нарастающие со временем и влияющие на принятие решений шиншиллой, что порождает эмерджентные поведенческие паттерны.

## Архитектура

### Основные компоненты

#### 1. **AffectCycle** (класс данных)

Представляет отдельные автономные циклы (голод, усталость, скука):

- **Естественный рост**: циклы нарастают со временем, пока потребность не удовлетворена
- **Спад насыщения**: быстрый спад, когда потребность удовлетворяется
- **Пороги**: критическое состояние и состояние удовлетворения
- **Ускорение от активности**: некоторые циклы (усталость) нарастают быстрее во время активности

#### 2. **SchedulingSystem** (главный класс)

Ведёт все автономные циклы:

- **Обновление циклов**: применяет изменения по активным цепочкам и времени
- **Предложения драйвов**: даёт оценки срочности для отбора цепочек
- **Циркадный ритм**: паттерны активности в зависимости от времени суток
- **Интеграция с аффектом**: изменяет аффективное состояние приращениями циклов

### Параметры циклов (реалистичные периоды около 20 минут)

| Цикл | Скорость роста | Скорость спада | Критический | Удовлетворён | Примечание |
|-------|---------------|------------|----------|-----------|-------|
| Голод | 0.0008/сек | 0.08/сек | 0.75 | 0.2 | Поведение поиска пищи |
| Усталость | 0.0006/сек | 0.1/сек | 0.7 | 0.15 | Поведение сна и отдыха |
| Скука | 0.0012/сек | 0.06/сек | 0.8 | 0.25 | Поведение игры и исследования |

**Время до критического состояния**: около 15–20 минут на цикл при реалистичных скоростях

### Отбор цепочек на основе драйвов

Система даёт взвешенные предложения для отбора цепочек:

```python
drives = scheduler.get_drive_suggestions()
# Returns: {'eating': 0.4, 'bedtime_routine': 0.1, 'play': 0.6, ...}
```

**Формула суммарного веса:**

```
combined_weight = 1.0 + (learned_weight - 1.0) * 0.5 + drive_weight * 0.3
```

Где:

- **Базовый вес**: 1.0 (нейтральный)
- **Выученный вес**: предпочтения на основе памяти (±0.5)
- **Вес драйва**: срочность цикла (0–0.8)

Цепочки отбираются только если `combined_weight > 0.8`.

# Update scheduling system
active_chains = {"eating": 1} if eating else {}

## Эмерджентность поведения

### Цикл голода

- **Нарастание**: естественный рост в период бездействия
- **Критическое состояние**: значение выше 0.75 запускает срочный поиск пищи
- **Насыщение**: цепочка еды быстро снижает голод
- **Следствие**: шиншилла сильнее мотивирована есть по мере роста голода

### Цикл усталости

- **Нарастание**: растёт во время активности (уход за собой, игра)
- **Критическое состояние**: значение выше 0.7 запускает поиск сна
- **Насыщение**: ритуал отхода ко сну быстро снижает усталость
- **Следствие**: активная игра естественно утомляет шиншиллу

### Цикл скуки

- **Нарастание**: самый быстрый рост, ведёт исследование
- **Критическое состояние**: значение выше 0.8 запускает срочный поиск игры
- **Насыщение**: цепочки игры и исследования снижают скуку
- **Следствие**: при скуке шиншилла ищет стимуляцию

### Циркадный ритм

- **Двадцатиминутный цикл дня и ночи** в симуляционном времени
- **Уровень активности**: sin(phase × π) создаёт естественные паттерны активности
- **Ночной эффект**: небольшое повышение усталости в «ночь»
- **Дневной эффект**: более высокая активность в «день»

## Эмерджентное поведение

Система создаёт реалистичные поведенческие паттерны:

1. **Еда, ведомая голодом**: шиншилла естественно ищет пищу по мере нарастания голода
2. **Усталость, вызванная активностью**: игра и исследование ведут к естественной усталости
3. **Игра, ведомая скукой**: при бездействии шиншилла ищет стимуляцию
4. **Циркадные паттерны**: уровни активности следуют циклам дня и ночи
5. **Выученные предпочтения**: система памяти смещает выбор к успешным поведениям
6. **Конкуренция потребностей**: несколько драйвов конкурируют за отбор поведения
